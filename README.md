# Climb Game — 네 손가락 클라이밍

모바일 화면의 좌우에 손가락을 두 개씩 배치해 **왼손·왼발·오른손·오른발을 각각 조작하는 클라이밍 게임**의 설계 저장소입니다.

**현재 단계: 설계 v0.4 완료, 2026-10-30(KST) 개발 착수.** 진행 순서는 [23. 개발 착수 검토](docs/23_dev_readiness_review.md)를 따릅니다. 아직 실행 프로젝트·빌드는 없습니다. 문서에 있는 기능·성능·일정은 제안 및 검증 목표이며 구현 완료를 의미하지 않습니다.

v0.4에서는 사용자 제공 참고 이미지 REF01을 분석하고, 일러스트풍 3D의 색감·윤곽선·재질·조명·캐릭터·벽 제작 기준에 반영했습니다. [참고 분석과 아트 방향](docs/22_reference_art_direction.md)에서 관찰 사실과 제작 제안을 구분합니다. 화면·설정·레벨 저작을 정리한 [v0.3 인계 기록](docs/21_design_readiness_v0_3.md), 입력·자세·복구를 정리한 [v0.2 검토 기록](docs/17_design_review_v0_2.md)은 당시 이력으로 보존합니다.

## 한눈에 보는 제안

| 항목 | 기본 설계안 |
| --- | --- |
| 플레이 | 다음 홀드를 고르고 → 한 팔다리를 옮기고 → 자세를 안정시키며 완등 |
| 조작 | 왼쪽 위=왼손, 왼쪽 아래=왼발, 오른쪽 위=오른손, 오른쪽 아래=오른발 |
| 멀티터치 | 최대 네 팔다리를 동시에 독립 조작. 입력 순서와 무관하게 조작 영역으로 배정 |
| 잡기 | 드래그로 기존 홀드를 놓고 이동, 유효한 홀드에서 손가락을 떼면 잡기 |
| 유지 | 한 번 잡은 홀드는 터치 없이 유지. 네 손가락을 계속 누를 필요는 없음 |
| 화면 | 가로 화면, 고정 시점의 3D 표현, 이동 판정은 벽면의 2차원 평면 |
| 아트 | REF01 기반 일러스트풍 3D, 얇은 윤곽선·무광 질감·따뜻한 흙빛 팔레트 |
| 엔진 | Godot 4.7.2 + GDScript 제안. 개발 착수 때 버전 재확인 후 고정 |
| 우선 플랫폼 | Android 우선, iOS 후속 검증 |
| 첫 제품 | 튜토리얼 3개 + 일반 루트 9개, 실내 벽 1테마, 캐릭터 1종 |
| 운영 | 오프라인, 로컬 저장, 계정·서버·광고·결제 없음 |

## 참고 이미지 상태

**참고 이미지 수신·분석 완료:** 사용자가 제공한 44439.jpg를 REF01로 지정했습니다. SNS 화면 안의 가로 게임 장면을 기준으로 얇은 선, 넓은 명암, 주황·갈색·올리브 벽과 청록 계열 인물을 분석했습니다. 이를 우리 고정 시점과 네 패드에 맞춰 적용하는 기준을 06/20/22 문서에 정리했습니다.

## 이후 개발 단계에서 검증할 것

1. 실제 휴대폰에서 네 손가락을 쓰기 편한지와 손·발 오조작 여부.
2. 홀드를 옮길 때 몸통이 자연스럽게 따라오고, 떨어진 이유를 이해할 수 있는지.
3. 실제 참고 이미지와 비교한 한 장면의 아트 품질과 기기 성능.

현재는 문서만 검토했습니다. 멀티터치, 물리, 성능 및 사용자 테스트 결과는 아직 없습니다. 위 검증은 이번 설계 작업의 완료 조건이 아니며 이후 개발 요청 범위에서 진행합니다.

화면 배치도는 개념 설명용입니다. 구현용 패드 좌표와 고정 플레이 시야는 [05. 화면과 UX](docs/05_screens_and_ux.md)를 따릅니다.
