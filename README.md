# Climb Game — 네 손가락 클라이밍

모바일 화면의 좌우에 손가락을 두 개씩 배치해 **왼손·왼발·오른손·오른발을 각각 조작하는 클라이밍 게임**의 설계 저장소입니다.

**현재 단계: 설계 초안 v0.1 / 2026-10-29(KST). 게임 구현은 시작하지 않았습니다.** 실행 프로젝트, 게임 소스코드, 빌드 파일은 없습니다. 문서에 있는 기능·성능·일정은 제안 및 검증 목표이며 구현 완료를 의미하지 않습니다.

## 한눈에 보는 제안

| 항목 | 기본 설계안 |
| --- | --- |
| 플레이 | 다음 홀드를 고르고 → 한 팔다리를 옮기고 → 자세를 안정시키며 완등 |
| 조작 | 왼쪽 위=왼손, 왼쪽 아래=왼발, 오른쪽 위=오른손, 오른쪽 아래=오른발 |
| 멀티터치 | 최대 네 팔다리를 동시에 독립 조작. 입력 순서와 무관하게 조작 영역으로 배정 |
| 잡기 | 드래그로 기존 홀드를 놓고 이동, 유효한 홀드에서 손가락을 떼면 잡기 |
| 유지 | 한 번 잡은 홀드는 터치 없이 유지. 네 손가락을 계속 누를 필요는 없음 |
| 화면 | 가로 화면, 고정 시점의 3D 표현, 이동 판정은 벽면의 2차원 평면 |
| 엔진 | Godot 4.7.2 + GDScript 제안. 개발 착수 때 버전 재확인 후 고정 |
| 우선 플랫폼 | Android 우선, iOS 후속 검증 |
| 첫 제품 | 튜토리얼 3개 + 일반 루트 9개, 실내 벽 1테마, 캐릭터 1종 |
| 운영 | 오프라인, 로컬 저장, 계정·서버·광고·결제 없음 |

## 참고 이미지 상태

요청에는 유사한 이미지 퀄리티가 명시되어 있지만, 이번 작업에서 확인 가능한 메시지와 최초 저장소에는 참고 이미지가 없었습니다. 따라서 **특정 이미지와 일치하는 스타일·캐릭터·색감·완성도를 확정하지 않았습니다.** 아트 문서는 제작 기준과 비교 절차를 정의하고, 실제 참고 이미지 확인 후 시안 및 아트 범위를 확정하도록 구성했습니다. 아래 와이어프레임은 배치 검토 자료이며 최종 게임 그래픽이 아닙니다.

## 먼저 검증할 것

1. 실제 휴대폰에서 네 손가락을 쓰기 편한지와 손·발 오조작 여부.
2. 홀드를 옮길 때 몸통이 자연스럽게 따라오고, 떨어진 이유를 이해할 수 있는지.
3. 실제 참고 이미지와 비교한 한 장면의 아트 품질과 기기 성능.

현재는 문서만 검토했습니다. 멀티터치, 물리, 성능 및 사용자 테스트 결과는 아직 없습니다. 개발 시작 요청 전까지 설계만 보완합니다.
