# 남녀 캐릭터 제작 기준 (더미 몸, docs/39)

2026-11-13. 게임 판정 몸 = 더미(`reference_climber.glb`). 그림·3D 모두 이 관절 위치에 맞춘다. 게임은 뼈 위치가 1cm 넘게 다르면 모델을 쓰지 않는다(캡슐 인형).

## 1. 그림(T포즈 4장)

- 4장: 정면 / 왼쪽을 보는 옆 / 뒤 / 오른쪽을 보는 옆. 같은 캔버스, 같은 정수리·발바닥 선.
- 캔버스 1536 × 1536px, 순백 배경(체크무늬·그림자 없음), 원근 없이 평평하게(직교).
- 정수리(머리카락 제외) y = 150, 발바닥 y = 1450 → 키 1300px, 1% = 13px, 몸 가운데 x = 768.
- 기준선 그림: `draw_template_front.png`(이 폴더). 아래 층에 깔고 그린다.
- 색은 단색 면 + 외곽선. 옷의 주름·그림자·명암을 그리지 않는다(Tripo가 텍스처에 구워 얼룩이 된다).
- 옆모습 2장은 팔이 카메라 쪽·반대쪽을 향하므로 어깨에 짧게 보이는 팔(주먹·어깨 원)로 그린다.

## 2. 의상·장비

- 하의: 골반부터 발목까지 한 벌, 가랑이는 고관절 아래 약 9cm(밑위가 긴 바지 금지).
- 하네스(보라): 허리띠는 골반, 다리 고리는 각 허벅지. 초크백(회색): 착용자 오른쪽 뒤 허리(뒤에서 볼 때 화면 오른쪽).
- 신발: 앞코가 발끝(발목 앞 19cm). 홀드를 디디는 점.

## 3. 3D 생성(Tripo)

- 모델 v3.1, 멀티뷰 4장(정면·왼쪽·뒤·오른쪽 순서), 텍스처 켬. 삼각형은 게임용 변환에서 1만 2천으로 줄인다.
- 결과 glb를 `art_source/character/male|female/`에 둔다.

## 4. 게임용 변환(`art_source/character/build_tripo_rig.py`)

1. Tripo 결과(키 1로 정규화, 발바닥 0)에서 기준점 5개를 잰다: 팔 중심선 높이, 발목 관절 높이, 무릎 높이, 손끝 |x|, 가랑이 높이. 초크백 위치(판별식)도 적는다.
2. 스크립트 CFG의 `landmarks`·`chalk`에 넣는다.
3. `TRIPO_CHAR=male|female blender -b --python art_source/character/build_tripo_rig.py`
   → 크기(어깨~발목 1.30m), 다리(무릎 −0.41), 팔(손끝 0.975)을 더미 몸에 맞추고 뼈대·가중치·윤곽선 굵기를 넣어 `game/art/characters/climber_male|female.glb`를 만든다.
4. `game/data/characters.json`에 몸으로 등록한다(지금은 더미 1종).
