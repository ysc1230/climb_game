# 주름을 최소화한 청바지 캐릭터 — 제작 입력 v1

2026-11-12. 상태: 외형 설계 및 AI 생성 참고 이미지. 3D 생성·리깅·등반 변형 검증 전.

## 설계

- 기존 인상을 유지한 카툰풍 남성. 둥근 갈색 머리, 흰 반팔, 청회색 바지, 회색 클라이밍화, 오른쪽 허리 뒤 회색 초크백.
- 길고 가는 팔다리. 약 7등신을 이미지 생성 목표로 설정했으며, 정확한 3D 치수나 게임의 도달 거리를 변경한 것은 아니다.
- 바지는 약간의 여유가 있는 슬림 스트레이트 핏. 레깅스처럼 붙거나 무릎·발목에 천이 뭉치지 않게 한다.
- 청바지 느낌은 청회색, 앞주머니 곡선, 평평한 뒤 주머니 두 개, 얇은 봉제선으로 전달한다.
- 기본형에는 바지 주름을 넣지 않는다. 특히 사타구니·엉덩이 밑의 고정된 검은 그림자, 깊은 홈, 삼각형 주름을 배제한다.
- 골반에서 허벅지까지 한 옷으로 이어지는 표면. 중앙 솔기는 얕게, 측면 둔부는 자연스럽게 둥글게 만든다. 정상적인 두 다리 사이 공간까지 메우는 설계가 아니다.
- 초크백은 골반에 부착하는 독립 부위로 제작하고 허벅지 변형의 영향을 받지 않도록 한다.
- 제작용 이미지는 부드러운 중립 조명으로 한다. 최종 게임의 셀 셰이딩·윤곽선은 이후 적용한다.

## 이미지와 입력 순서

| 파일 | 시점 | 확인할 특징 |
| --- | --- | --- |
| front.png | 정면 | 초크백이 화면 왼쪽에 일부 보임 |
| left.png | 캐릭터 왼쪽 측면, 얼굴이 화면 왼쪽 | 반대편 초크백은 대부분 가려짐 |
| back.png | 후면 | 초크백이 화면 오른쪽, 평평한 두 뒤 주머니 |
| right.png | 캐릭터 오른쪽 측면, 얼굴이 화면 오른쪽 | 뒤쪽 초크백이 보임 |

한 파일에 한 명만 들어 있는 개별 PNG다. Tripo 멀티뷰에 front → left → back → right 순서로 지정한다. 측면에서 손이 짧아 보이는 것은 팔을 내린 자세가 아니라 카메라 방향으로 뻗은 T포즈의 단축 표현이다.

이미지 생성은 built-in image_gen을 사용했다. 최종 프롬프트는 prompts.json에 보존한다. Tripo 작업은 이번 단계에서 제출하지 않았다(Tripo 크레딧 사용 0).

## 검수 범위와 다음 제작 단계

네 이미지의 전신 프레이밍, T포즈, 바지 주름 억제, 의상 및 초크백 좌우 위치를 시각 확인했다. 생성 이미지이므로 픽셀 단위로 동일한 투영이나 정확한 입체 정합을 보증하지 않는다. 손가락, 헤어 덩어리, 봉제선과 허리 높이의 세부 차이는 모델 제작 때 정리한다.

이미지는 외형 지시만 한다. 연속된 토폴로지, 웨이트, 리깅 품질을 보증하지 않는다. Tripo 결과는 먼저 단색 재질로 검사하고 골반의 구멍·깊은 홈·허벅지 연결을 점검한다. 필요하면 하체를 재제작한다.

높게 무릎 들기와 옆으로 다리 뻗기, 각각의 좌우 반전과 중간 자세를 검수한다. 보정 셰이프가 필요하면 Godot 구동까지 연결해 검증한다. 주름 없는 기본형이 통과한 뒤에만 무릎·발목에 얕은 디테일을 선택적으로 추가한다. 기준은 [캐릭터 재설계](../../../../docs/28_character_rebuild.md)다.
