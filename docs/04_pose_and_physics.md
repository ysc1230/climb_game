# 04. 자세·물리·IK 설계

설계 v0.5 · 2026-10-31(KST) · 설계 수치의 단일 기준

**길이 안의 자유 이동을 허용하는 모델에서, 접점·하중·관절·연속 경로를 함께 제한하는 모델로 변경한다.** 아래 수치는 게임 제작을 위한 초깃값이다. 사람의 의학적 가동 범위, 타 게임의 내부 수치, 실행 검증 결과가 아니다. 이번 작업은 소스 수정과 실행 검증을 포함하지 않는다.

조사와 현재 코드의 빈틈은 [24](24_climbing_motion_research.md), 상황별 동작과 검수 사례는 [25](25_movement_constraints_and_moves.md)를 따른다. v0.4의 거리 기반 목표 비용·지지 접점 개수만으로 움직임을 결정하는 방식은 이 문서로 대체한다. 입력 소유권은 [03](03_controls.md), 거래·시간은 [15](15_runtime_contract.md)의 책임이다.

## 1. 구조와 범위

벽면 X/Y 이동과 고정 시점은 유지한다. 다만 **판정용 자세에는 제한된 깊이와 몸통 방향을 포함**하여, 실제 3D 리그로 만들 수 없는 자세를 잡기 전에 거부한다. 기존 “Z는 시각 전용이므로 길이 판정에 무관”이라는 규칙을 폐기한다. 자유 3D 이동이나 자유 회전 카메라를 추가하는 것은 아니다.

PoseSolver가 판정 자세와 관절 위치·프레임을 생성한다. 표현 계층은 이 결과를 읽고 메시를 배치한다. 표현 계층만의 다른 IK 해가 판정에 없는 회전·도달을 만들면 안 된다. 몸통에 엔진 강체와 자세 계산기가 동시에 힘이나 회전을 쓰지 않는다.

| 계층 | 책임 |
| --- | --- |
| 접점 | 슬롯 점유, 종류, 접촉 방향과 발판의 회전 허용 |
| 자세 | 골반 위치, 몸통 방향, 실제 뼈 길이·각도, 관통 없는 관절 위치 |
| 지지 | 허용 접점 힘, 벽면 내 균형, 손별 하중, 회복 가능 여부 |
| 무브 | 현재 자세에서 가능한 이동 목적과 단계. 하드 제약을 완화하지 않음 |
| 표현 | 확정 관절 프레임, 손가락·호흡·피로 표시. 판정 접점과 몸통을 변경하지 않음 |

실제 등반의 3D 접촉 역학 전체를 재현하지 않는다. 지지 계산은 벽면 내의 준정적 근사이며, 벽 밖으로 열리는 회전인 barn door를 완전하게 시뮬레이션하지 않는다. 그 방향의 폭주는 별도의 몸통 방향·관절·접촉 제약으로 막는다. 지상 보행의 “무게중심이 발의 지지 다각형 안” 규칙을 수직벽에 그대로 적용하지 않는다.

## 2. 좌표와 체형

월드 1단위=1m, X 오른쪽, Y 위, Z 벽 바깥쪽이다. 벽 기준면은 Z=0이다. 캐릭터의 앞은 벽 쪽(-Z), 뒤는 카메라 쪽(+Z)이다. L/R은 신체 ID이며 손발이 화면 반대편으로 가도 바뀌지 않는다.

| 항목 | 기준 |
| --- | --- |
| 팔 위/아래 길이 | 0.40 / 0.38m |
| 다리 위/아래 길이 | 0.52 / 0.48m |
| 어깨 기준 위치 | 골반 기준 X ±0.20, Y +0.55m. 가슴 방향으로 변환 |
| 고관절 기준 위치 | 골반 기준 X ±0.14, Y 0m. 골반 방향으로 변환 |
| 명목 팔 거리 | 0.20~0.78m |
| 명목 다리 거리 | 0.25~1.00m |
| 팔꿈치 굽힘 | 5~155°. 완전히 펴짐=0°, 역방향 굽힘 불가 |
| 무릎 굽힘 | 5~145°. 완전히 펴짐=0°, 역방향 굽힘 불가 |

두 뼈 길이 a,b와 굽힘 φ에서 실제 거리는 √(a²+b²+2ab cos φ)다. 유효 거리는 이 범위와 명목 범위의 교집합이다. 실제 3D 관절→말단 거리로 검사한다. 2D 거리만 맞춘 뒤 뼈를 늘리거나 골반을 벽 속으로 넣어 맞추지 않는다. 다리 최솟값은 약 0.303m이며, Free/Dragging도 같은 최솟값을 지킨다.

## 3. 절대로 넘을 수 없는 제약

아래 검사에는 힘이 빠진 상태·보조 모드도 예외가 없다. 의도적인 접점 해제는 허용하지만, 해제한 말단이 관절 한계를 뚫고 움직이는 것은 허용하지 않는다.

| ID | 검사 | 실패 시 |
| --- | --- | --- |
| H01 | 골반·가슴의 벽 기준 절대 각도와 상대 비틀림 | 요청 방향의 이동을 경계에서 멈춤 |
| H02 | 모든 팔다리의 최소·최대 3D 거리 및 굽힘 | 가까운 연속 유효 위치로 제한, 길이 보정 금지 |
| H03 | 어깨·고관절 방향 영역과 부모 뼈 기준 twist | 금지 방향을 도달 영역에서 제거 |
| H04 | 고정 접점 위치·접촉 방향·슬롯 점유 | 기존 접점 유지. 불가능한 신규 접점만 거부 |
| H05 | 몸통·머리·사지와 벽·몸의 충돌 | 몸을 통과하는 최단 경로 대신 이동 중단 |
| H06 | 직전 확정 자세에서 다음 자세까지의 연속 경로 | 끝점만 가능한 반대편 해로 점프 금지 |
| H07 | 속도·가속도·유한 수·정규화된 회전 프레임 | 정상 한계는 제한, 구조·수치 오류는 틱 롤백 후 정지 |

### 회전의 의미와 제한

roll θ는 벽면에서의 좌우 기울기(Z축), yaw는 벽을 향한 상태에서 몸을 옆으로 트는 각도(Y축), pitch는 벽 쪽/바깥쪽 숙임(X축)이다. 가슴과 골반의 각도를 각각 저장하고, 몸통 roll은 공유한다. 합성 순서는 벽 기준에서 yaw → pitch → roll로 정의한다. 부모·휴지 자세의 기준 축은 리그 명세에 고정한다.

| 값 | v0.5 상한/초깃값 | 적용 |
| --- | --- | --- |
| body_roll_limit | ±25° | 골반·가슴의 공통 벽면 기울기 |
| pelvis_yaw_limit / chest_yaw_limit | ±40° / ±45° | 벽 반대 방향을 향하거나 한 바퀴 회전 불가 |
| chest_pelvis_yaw_delta | 20° 이하 | 허리를 축으로 가슴만 돌리지 못함 |
| pelvis_pitch_limit / chest_pitch_limit | ±10° / ±15° | 앞뒤로 쓰러지는 자세 제한 |
| chest_pelvis_pitch_delta | 10° 이하 | 허리의 과도한 앞뒤 꺾임 제한 |
| side_on_yaw_target | 좌/우 30° | 사이드온·드롭니 목표. 상한이 아님 |
| orientation_speed / acceleration | 90°/s / 360°/s² | 모든 몸통 방향 성분에 적용 |
| presentation_joint_speed | 180°/s | 뼈 방향·twist 연속성 검수 상한 |
| pelvis_depth_range | 0.20~0.42m | 실제 접점 깊이와 길이·벽 충돌을 함께 충족해야 함 |

각도는 벽/휴지 자세 기준의 제한된 절대 상태다. 이전 프레임 회전에 회전량을 계속 곱해 원점을 잃지 않는다. 360°를 0°로 정규화해서 불법 상태를 합격시키지 않는다. 경계에서 바깥으로 향하는 각속도 성분은 0으로 만들며 다음 틱에 회전 에너지가 쌓이지 않게 한다.

Falling에서도 몸통의 전신 회전을 새로 허용하지 않는다. 접점을 모두 해제하고 골반의 중력 낙하만 수행하며, 진입 때의 제한된 방향에서 사지가 아래로 정리된다. 반복 회전 래그돌은 이번 범위에 없다.

### 방향 영역과 관절 비틀림

2D 조작 영역을 먼저 제한하고, 그 안에서 3D 관절 해를 검사한다. 두 검사의 교집합만 허용한다.

| 항목 | 시작 제한과 기준 축 |
| --- | --- |
| 손 말단 방향 | 몸통 roll을 제거한 어깨→손 벡터 v에서 atan2(s·v.x, v.y)가 -100~170°. s는 왼쪽 -1, 오른쪽 +1 |
| 발 말단 방향 | 골반 roll을 제거한 고관절→발 벡터 v에서 atan2(s·v.x, -v.y)가 -60~110°. 교차는 별도로 3D 충돌·관절 검사 |
| 상완 방향 | 가슴 로컬의 벽 쪽(-Z) 축을 중심으로 반각 120°의 swing 원뿔 |
| 대퇴 방향 | 골반 로컬의 아래(-Y) 축을 중심으로 반각 125°의 swing 원뿔 |
| 상완 / 전완 축 twist | 부모·휴지 프레임 기준 ±70° / ±80° |
| 대퇴 / 하퇴 축 twist | 부모·휴지 프레임 기준 ±45° / ±10° |
| 손목 / 발목 축 twist | 접촉 프레임 기준 ±45° / ±25° |
| contact_frame_angular_tolerance | 고정 접촉 프레임 오차 5° 이하. pivot 허용 시에만 슬롯의 허용 회전 축에서 발목 twist 범위 사용 |

twist는 해당 뼈의 길이 축 주위 회전이다. swing과 분리해 검사하며, 월드 Euler 성분을 잘라 같은 효과라고 간주하지 않는다. 굽힘의 좌우 branch/pole은 이전 해에서 연속적으로 유지한다. 완전 펴짐·원점 부근을 거쳐 무릎이 반대편으로 뒤집히는 전환은 금지한다.

손의 좌우 교차는 허용 영역 안의 명시적 CrossReach로 가능하다. “LH는 항상 화면 왼쪽” 같은 제한은 사용하지 않는다. 발의 깊은 교차와 뒤로 감기는 자세는 위 방향·충돌 제약으로 제한한다.

### 충돌과 접촉

기존 몸통 캡슐(골반 로컬 Y 0.10~0.48m, 반경 0.18m)과 머리 구(중심 Y 0.78m, 반경 0.13m)를 3D에 적용한다. 사지에는 팔 반경 0.035m, 다리 0.045m의 저해상도 캡슐을 추가한다. 같은 관절을 공유하는 인접 뼈와 몸통 부착부의 정해진 연결 구간만 충돌 제외한다. 반대 팔·다리 전체를 충돌 제외하지 않는다.

교차하는 팔은 벽 바깥쪽의 허용된 깊이 경로를 사용할 수 있지만, 3D 길이·관절·속도 검사를 그대로 통과해야 한다. 깊이를 늘려야 길이가 모자라면 교차를 거부한다. 접촉 패치만 홀드 표면 접촉을 허용하며, 손발·머리가 벽이나 다른 장애물을 통과하지 않는다. 접촉 방향은 슬롯의 authored frame을 따르고, 발의 pivot_allowed가 false이면 붙은 발끝을 축으로 몸을 비트는 무브를 금지한다.

## 4. 붙은 접점과 지지 하중

각 말단에 세 값을 분리한다.

- Attached: 슬롯을 점유하고 접촉 위치가 고정되어 있다.
- LoadEligible: 현재 자세와 슬롯의 힘 방향에서 하중을 받을 수 있다.
- Loaded: 지지 계산에서 실제 하중이 배정되었다.

손은 일반 pull 슬롯에서 접점이 어깨보다 0.10m 이상 낮으면 하중 자격을 잃는다. 낮은 손을 아래로 눌러 올라서는 mantle은 별도 접촉 유형이 필요하므로 이번 기본 무브에 포함하지 않는다. 발은 슬롯→고관절 방향이 지지 원뿔 안이고 고관절보다 낮아야 한다. 기존 발 지지 반각 60°·높이 0.05m·종료 히스테리시스 5°/0.01m를 유지한다. 발을 높이 올려 놓기만 한 상태는 Attached이면서 아직 Unloaded일 수 있다.

### 벽면 내 준정적 지지 계산

힘은 캐릭터 체중을 1로 정규화한 BW 단위로 다룬다. 접점 위치 p와 무게중심 대리점 c는 3D 자세를 벽면 XY로 투영한 값이다.

무게중심 대리점은 몸통·머리 중심 0.60, 좌우 팔 각각 0.05, 좌우 다리 각각 0.15의 가중 평균이다. 몸통·머리 중심은 골반과 머리 중심의 중점, 팔·다리 중심은 각 체인의 세 관절 위치 평균이다. 이는 게임용 가중치이며 실제 인체 분절 질량을 측정한 값이 아니다.

각 지지 가능한 슬롯에 force_axis, force_half_angle, max_load를 둔다. 축·양쪽 경계의 세 단위 방향을 조합한 비음수 힘만 허용하고, 조합 계수 합이 max_load 이하이어야 한다. 발에 음수 하중을 주어 매달리는 해는 불허한다.

지지 가능한 자세는 다음을 만족하는 힘 배분이 존재하는 자세다.

- 접점 힘의 합이 위쪽 1BW와 균형을 이룬다. 수평 힘 합은 0이다.
- c 주위 벽면 내 모멘트 합이 0이다.
- 모든 접점의 힘 방향과 용량을 지킨다.

힘 잔차 허용치는 0.02BW, 모멘트 잔차는 0.02BW·m다. 방향의 편차를 무시하고 접점 좌표만 평균 내어 몸통 목표를 정하지 않는다. 이 해법은 벽면 밖 모멘트나 마찰계수를 추정하지 않는다.

| 조정값 | 초기값 |
| --- | --- |
| 일반 손 슬롯 힘 축 / 반각 / 최대 하중 | 위 (0,1) / 65° / 1.10BW |
| 일반 발 슬롯 힘 축 / 반각 / 최대 하중 | 위 (0,1) / 60° / 1.30BW |
| loaded_foot_enter / exit | 0.05 / 0.03BW |
| stable_load_ratio | 모든 접점 사용률 u≤0.80 |
| recover_hand_load_ratio | 각 손 u≤0.35 |
| load_cost_hand / foot | 2.0 / 1.0 |
| load_solution_regularizer | 조합 계수 제곱합 가중치 0.001 |
| imbalance_recovery_ticks | 18틱(0.30초), Paused에서 보존 |

사용률 u는 슬롯의 조합 계수 합/max_load다. 여러 해가 있으면 정규화된 손·발 하중 제곱의 가중합과 작은 계수 정규항을 최소화한다. 같은 입력·자세에 같은 해를 선택하고 이전 지지 발의 유무만으로 힘을 만들어내지 않는다. 위 수치로 모든 루트가 풀린다고 보장하지 않는다.

힘 계산 결과는 Feasible / Infeasible / Unresolved로 구별한다. 허용 오차 안의 해 또는 제약 불가능 판정을 얻지 못한 예산 초과·수치 실패는 Unresolved다. 이를 플레이어의 불균형으로 단정하지 않고 이전 틱으로 롤백해 정지·진단한다. 몸통 목표 탐색의 국소 정지는 정상 Blocked 결과이며 힘 계산의 수치 실패와 별개다.

| 상태 | 조건 | 허용 동작 |

| SupportedStable | 힘·모멘트 해 존재, u≤0.80, 최소 유효 손 또는 플랫폼 | 허용 무브와 회복 평가 |
| SupportedStrained | 힘·모멘트 해 존재, 일부 u>0.80 | 제한된 이동, 피로 소모, 회복 금지 |
| Rebalancing | 손/플랫폼 자격은 남았으나 접점 변화 뒤 힘의 균형이 불가능 | 18틱 안에 균형 오차를 줄이는 자세·말단 이동과 재잡기 |
| Grace | 유효 손이 없고 플랫폼도 없음 | 기존 9틱 유예. 몸통 정지, 말단·재잡기만 |
| Falling | Grace 또는 Rebalancing 시간 초과, 정상 실패 | 접점 해제·낙하, 재잡기 불가 |

Rebalancing에서는 하드 제약을 모두 유지하고 힘 잔차를 줄이는 경로만 허용한다. 단순히 위로 올라가서 해결하는 상승 보너스는 없다. 새 접점이 추가되어 힘의 해가 생기면 복귀할 수 있다. 18번째 틱에도 재잡기·자세 계산을 먼저 평가하고, 끝까지 불균형이면 Falling으로 전환한다. 정상 실패이며 수치 오류 복구로 취소하지 않는다.

Rebalancing 중 무브 라벨 변경·새 down/up·일시정지로 카운트를 초기화하지 않는다. 유효한 균형이 6틱 연속 확정되어야 새 불균형 구간의 예산을 다시 얻는다. 첫 유효 틱부터 이동은 가능하지만 확인 카운트가 6 미만인 동안 성공 유지·회복은 진행하지 않는다. 무지지 Grace가 겹치면 둘 중 먼저 만료되는 실패를 적용한다. 두 예산을 번갈아 사용해 공중 정지를 연장할 수 없다.

정확한 카운터 정의: imbalance_ticks는 힘의 해가 없는 모든 틱(Grace 포함)에 1 증가하고, 힘의 해가 돌아오면 증가를 멈춘다. balance_confirm_ticks가 6에 도달할 때만 imbalance_ticks를 0으로 초기화한다. unsupported_ticks는 손/플랫폼 자격이 없는 연속 틱에 증가하고 자격이 생기면 0이 된다. 불균형이 남은 상태에서 18 또는 무지지 9가 되면 실패다. 새 시작은 두 카운터 0, 사전 검증된 균형 자세로 시작한다. 안정 확인 6번째 틱부터 목표 유지 카운트를 진행할 수 있다.

손이 하나라는 이유만으로 무조건 Supported로 만들지 않는다. 다만 최소 세 접점이라는 규칙도 없다. 한 손 지지가 실제 허용 방향·하중·자세를 통과하면 유지할 수 있다. 일반 벽에서 양발만으로 버티기는 금지하고, 지정 플랫폼에서만 예외다.

## 5. 무브 선택과 몸통 이동

무브 목록과 상황별 진입 조건은 [25](25_movement_constraints_and_moves.md)에 있다. 무브는 입력 소유권 상태와 독립된 해석 정보다. 네 손가락은 계속 독립 입력을 낼 수 있으며 애니메이션 하나를 끝내기 위해 나머지를 잠그지 않는다.

기본 순서는 의도 확인 → 남은 접점으로 체중 이동 → 해당 말단 이동 → 실제 접점 확인 → 새 접점에 하중 싣기다. 이미 조건이 충족되면 준비 단계는 즉시 지나갈 수 있다. 의도적인 detach는 즉시 반영하고, 이후 남은 접점의 균형을 계산한다. 가상의 접점을 남겨 준비 시간을 벌지 않는다.

목표 탐색은 직전 확정 자세에서 시작한다. 현재 무브와 좌우 대안의 제한된 자세 프로필을 평가하되, 같은 비용이면 현재 프로필·이전 자세에 가까운 해·고정 ID 순으로 고른다. 새 프로필이 6틱 연속 유효하고 비용이 0.02 이상 개선될 때 바꾼다. 현재 프로필이 하드 제약을 깨면 즉시 대체 가능한 연속 경로를 찾거나 경계에서 멈춘다.

| 비용 | 정의와 초기 가중치 |
| --- | --- |
| 조작 목표 오차 | 각 활성 말단의 목표까지 거리/그 팔다리 최대 길이의 제곱합 × 1.0 |
| 손 하중 | 각 손 u²의 합 × 1.0 |
| 선호 팔다리 자세 | 각 거리와 무브별 선호 거리의 오차/최대 길이 제곱합 × 0.5 |
| 몸통 각도 여유 | roll/25, yaw/각 상한, pitch/각 상한의 제곱합 × 0.2 |
| 직전 자세와 변화 | 골반 변위/0.30m와 각도 변화/15°의 제곱합 × 0.1 |

무브별 팔 선호 거리는 Rest 0.70m, Reach/Traverse 0.60m, LockOff 0.42m이며, 다리는 기본 0.78m, StandUp/Rest 0.86m다. 선호값은 강제 길이가 아니다. 기존의 모든 상황에서 팔 0.52m를 선호하던 비용을 폐기한다. 힘 해를 통과하지 못한 후보는 비용이 작아도 정상 목표로 선택하지 않는다.

| 무브 판별 조정값 | 초기값 |
| --- | --- |
| high_step_below_hip | 0.20m. 발 목표 Y≥고관절 Y−이 값이면 HighStep 후보 |
| flag_cost_improvement | 0.02 이상. 균형 해가 없으면 정규화된 힘/모멘트 잔차 제곱합의 개선으로 비교 |
| move_switch_confirm_ticks / cost_margin | 6틱 / 0.02 |
| balance_confirm_ticks / rest_confirm_ticks | 각각 6틱. 힘의 해 유지와 휴식 조건 유지의 별도 카운터 |

> **구현 편차(tuning_version 3, 2026-10-31):** ① 손 하중 u² 항은 후보마다 힘 계산이 필요해(1회 약 0.5ms×후보 216개) 대신 "골반이 하중 발 X 범위 위에 있도록"(StandUp이면 올린 발 위) 끄는 대체 항(가중치 1.0, 척도 0.30m)을 쓴다. 힘 균형은 이동 수락 단계에서 별도로 지킨다. ② 선호 팔다리 자세 항은 붙은 모든 팔다리에 적용한다(지지에서 빠진 높은 발 포함). 그렇지 않으면 골반을 내려 다리 비용을 없애는 거짓 해가 생긴다. ③ 조작 목표 오차에 "요청 목표를 접점으로 더했을 때의 공통 골반 깊이 충돌" 항을 더한다. ④ 활성 말단 구성이 바뀌면 무브 라벨을 즉시 바꾸고, 같은 구성 안의 라벨 변경만 6틱 확인한다(비용 0.02 개선 조건은 미적용). 근거와 측정은 [23](23_dev_readiness_review.md)의 무브 구현 기록.

탐색 범위는 한 틱 시작점에서 위치 0.30m·각도 15° 안이다. 초기 탐색 간격은 XY 0.04m, Z 0.02m, 각도 3°이며 개선이 없으면 절반으로 줄인다. 최대 8라운드·전체 512후보를 공유 상한으로 둔다. 이는 시작 설계이며 모바일 성능을 측정한 값이 아니다. 예산 안에 개선해가 없으면 현재 유효 자세를 유지한다. 내부 계산 오류와 “요청한 곳으로 갈 수 없음”을 구분한다.

목표를 즉시 적용하지 않는다. 골반의 위치 gain/damping·속도·가속도는 공통 표를 따르고, 각도 gain/damping은 30s⁻²/10s⁻¹로 시작한다. 제안 이동량을 1, 1/2, 1/4, 1/8, 1/16, 1/32, 0배로 줄이며 경로가 유효한 첫 결과를 선택한다. 선택한 실제 변위로 속도를 다시 계산한다.

접점·조작 목표가 바뀌지 않으면 몸통이 유한한 자세로 수렴해야 한다. Y 증가 보너스, 접점을 다시 누를 때 높이를 추가하는 보정, 누적 회전 오프셋을 금지한다.

## 6. 도달 영역·경로·잡기

도달 가능 영역은 단순 원이 아니다. **현재 자세 또는 남은 접점을 보존하며 연속적으로 도달할 수 있는 가까운 자세에서, H01~H07과 지지 조건을 만족하는 말단 위치 집합**이다. 분리된 다른 해의 영역을 한 번의 드래그로 연결하지 않는다.

즉시 닿는 영역과 체중 이동이 선행되어야 하는 영역은 UI에서 구분한다. 두 번째 영역은 아직 잡을 수 있다는 뜻이 아니다. 요청 초과량은 경계에서 버려 반대 드래그에 즉시 반응한다. 단, 허용된 몸통 이동으로 접근 중인 목표는 그 이동 예산 안에서 유지한다.

잡기 순간에는 현재 실제 말단·현재 몸통으로 슬롯에 도달해야 한다. 후보 반경은 길이·각도·하중·충돌 제한을 늘리는 값이 아니다. 스냅도 실제 말단→슬롯의 짧은 경로와 접촉 프레임을 검사한다. release 후 계속 움직여 뒤늦게 붙이거나 몸통을 순간 이동시키지 않는다.

한 틱의 모든 활성 말단과 몸통을 함께 평가한다. 개별로 가능한 두 손 목표라도 함께 몸을 관통하거나 관절·균형이 불가능하면 양쪽 모두를 강제 적용하지 않는다. 기존 접점 우선과 새 접점 조합 우선순위는 15를 따른다.

경로는 최대 말단 변위 0.02m·관절 변화 2°마다 중간 자세를 확인하고 캡슐의 이동 구간을 검사한다. 샘플링만으로 연속 충돌을 보장한다고 주장하지 않는다. 출시 전 검수에서 빠른 입력·좁은 장애물에 대한 보수적 sweep을 통과해야 한다.

Free 손의 기본 휴식 목표는 골반 기준 (±0.35,+0.18m), Free 발은 (±0.25,-0.70m)다. Z와 최종 위치는 유효 영역 안에서 결정하며 속도 상한을 지킨다. Flag로 명확히 예고된 자유 발은 마지막 유효 목표를 유지할 수 있다(25의 MV06). 이 발은 접점·지지 발로 세지 않는다. Paused에서는 모두 정지한다.

## 7. 피로와 회복

손별 0~100, Free 손의 +15/s, 피로 0 손의 분리, 보조 모드의 감소 비활성화는 유지한다. 발 개수는 Attached 개수가 아니라 Loaded 개수다.

| 조건 | 붙은 손의 기본 변화율 |
| --- | --- |
| 안정 플랫폼, 정지, 회복 조건 충족 | +15/s |
| Loaded 발 2개, 안정·정지, 각 손 u≤0.35 | +10/s |
| Loaded 발 2개, 위 회복 조건 불만족 | -2/s |
| Loaded 발 1개, 붙은 손 2개 | -3/s |
| Loaded 발 1개, 붙은 손 1개 | -8/s |
| Loaded 발 0개, 붙은 손 2개 | -15/s |
| Loaded 발 0개, 붙은 손 1개 | -30/s |
| Rebalancing | 붙은 손 각각 -30/s, 회복 없음 |

정지는 몸통 속도 0.10m/s 이하이고 활성 이동 목표가 없는 상태다. 회복은 SupportedStable이 6틱 유지된 뒤 시작한다. 음수 변화율에는 max(1, 0.5+u)를 곱해 같은 접점 수에서도 더 큰 하중의 손이 빨리 지치도록 한다. Rebalancing에는 배율을 다시 적용하지 않는다. 양수 회복에는 배율이 없다. 보조 모드는 감소만 0으로 바꾸며 관절·힘의 가능 영역·실패 유예는 늘리지 않는다.

같은 홀드를 놓고 재잡아도 피로·불균형 예산을 초기화하지 않는다. 한 손이 미끄러지면 같은 틱 안에서 지지를 다시 평가한다. 마지막 손이 없어졌다면 그 틱부터 Grace를 계산한다.

## 8. 3D 회전·IK 표현 계약

1. 뼈마다 길이 축과 보조 축을 가진 완전한 직교 프레임을 만든다. 시작점→끝점 한 벡터만으로 몸통·사지 방향을 매 프레임 결정하지 않는다.
2. 리그의 휴지 축과 부모 좌표, 좌우 pole, 접촉 프레임을 명시한다. 첫 자식 뼈의 열거 순서가 신체 방향을 결정하지 않게 한다.
3. pole의 투영이 작아지면 이전 유효 보조 축을 평행 이동·재투영해 사용한다. 그것도 퇴화하면 같은 반구의 authored 보조 축을 사용하고, 연속 해가 없으면 직전 유효 자세에서 정지한다.
4. 부모·휴지 자세 기준 swing/twist를 제한한 뒤 최종 접점·길이를 다시 검사한다. 제한 후 접점이 어긋나면 뼈를 늘리지 말고 해당 자세를 거부한다.
5. Quaternion은 단위 길이를 유지하고 인접 프레임에서 부호를 맞춰 보간한다. q와 -q는 같은 회전이므로 큰 회전량으로 기록하지 않는다. 반대 방향 부근에 임의의 180° 회전을 넣지 않는다.
6. 렌더 보간도 관절 제한과 접점을 지킨다. 중간 자세가 불가능하면 확정 프레임을 유지하며, 보간으로 팔이 몸통을 가로질러 지나가지 않게 한다.
7. 호흡·흔들림은 접점 재검사 전의 제한된 보조 오프셋이다. UI 흔들림 끄기는 판정에 영향을 주지 않는다.
8. Skeleton 상대 좌표와 월드 좌표를 경계에서 변환한다. 정규 직교·양의 determinant·뼈 길이를 검사하고 비균일 스케일로 오류를 감추지 않는다.

이 계약은 향후 리그와 코드가 충족해야 할 기준이다. 현재 CH01의 twist·가중치 문제가 해결되었다는 의미가 아니다.

## 9. 오류·복구와 문서 검수

불가능한 목표·점유 충돌·힘의 불균형은 정상 게임 결과다. 수치 NaN, 중복 슬롯 점유, 검증된 이전 자세 자체의 손상은 내부 오류로 구분한다. 오류 틱은 시간·피로·접점·무브·유예와 미발행 이벤트까지 전부 롤백하고 즉시 정지한다. UI만 성공 소리를 먼저 내지 않는다.

앱 중단은 접점·방향·pole branch·불균형 카운트를 보존한다. 프로세스 종료 후에는 기존 계약대로 같은 버전의 시작/체크포인트로 복구한다. v0.5와 이전 조정 버전의 미완료 자세를 섞어 이어가기하지 않는다. 완료 기록은 보존하되 버전별로 분리한다.

[10](10_validation.md)의 기존 PH/DT와 [25](25_movement_constraints_and_moves.md)의 MC01~MC20을 후속 구현 검수에 사용한다. 이번에는 링크·규칙·수치 정의의 문서 일관성만 확인한다. 기존 R01 v2의 시뮬레이션 기록은 v0.4 조건의 결과이며, 이 3D 도달·하중·경로 제약의 통과 증거가 아니다.
