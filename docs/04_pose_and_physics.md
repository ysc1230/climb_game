# 04. 자세·물리·IK 설계

이 문서는 수치의 단일 기준이다. 아래 값은 모두 최초 프로토타입의 조정용 초깃값이며, 실측·생체역학 수치 또는 구현 완료 값이 아니다.

## 채택 구조

**게임 판정용 2D 자세 상태 + 제약된 몸통 운동 + 3D 스켈레톤 표현**을 제안한다. 보이는 캐릭터는 3D이고, 손발·몸통의 판정은 벽면 위 X/Y에서 수행한다. Z는 벽으로부터의 시각적 거리와 겹침 해소에만 사용한다. 손발을 홀드에 고정한 채 골반 위치와 몸통 기울기를 조정하고, 팔꿈치·무릎은 두 관절 IK로 연결한다.

| 방식 | 장점 | 부담 | 선택 |
| --- | --- | --- | --- |
| 전신 자유 래그돌 | 자연스러운 낙하·흔들림 | 떨림, 관절 폭주, 기기별 안정성 조정 | 기본 조작에는 사용하지 않음 |
| 애니메이션만 재생 | 예측·제어 쉬움 | 임의 홀드 배치와 독립 손발 조작에 부족 | 접촉·표정 보조에만 사용 |
| 제약 기반 자세 + IK | 네 말단 목표·접점을 직접 관리 | 몸통 이동과 제약 해결을 설계해야 함 | MVP 기본안 |

이는 사실적인 스포츠 시뮬레이션이 아니다. 단순화한 지지·피로 규칙으로 일관된 조작 경험을 만든다. 엔진 강체와 별도 자세 계산이 동시에 같은 몸통 위치를 쓰지 않게 한다.

## 좌표·크기 계약

월드 단위 1=1m로 작성한다. X는 오른쪽, Y는 위쪽, Z는 벽 바깥쪽이다. 루트 원점은 해당 벽 바닥 중앙이다. 모델 원점은 골반이다. 뼈와 슬롯은 명시한 로컬/월드 좌표를 변환해 사용하며 Skeleton3D의 스켈레톤 상대 global pose를 월드 좌표로 오해하지 않는다(S06).

| 항목 | 초기값 | 의미 |
| --- | --- | --- |
| 팔 위/아래 길이 | 0.40 / 0.38m | 총 0.78m, 좌우 동일 |
| 다리 위/아래 길이 | 0.52 / 0.48m | 총 1.00m, 좌우 동일 |
| 어깨 위치 | 골반 기준 X ±0.20, Y +0.55m | 기본 자세, 몸통 회전 반영 |
| 고관절 위치 | 골반 기준 X ±0.14, Y 0m | 몸통/골반 회전 반영 |
| 팔 도달 거리 | 0.20~0.78m | 어깨부터 손까지 |
| 다리 도달 거리 | 0.25~1.00m | 고관절부터 발까지 |
| 선호 팔/다리 거리 | 0.52 / 0.78m | 고정 길이가 아닌 자세 비용의 기준 |
| 몸통 회전 | 벽면에서 -25°~+25° | 극단적인 뒤집힘 방지 |
| 관절 각도 | 팔꿈치 굽힘 5°~155°, 무릎 5°~145° | 완전 펴짐=0°. 실제 허용 거리와 교집합 적용 |

도달 거리 최대값만 만족해도 관절 제한에 걸릴 수 있다. 유효성은 거리·관절·충돌을 함께 검사한다. 모델 비율 변경은 조작 범위·기존 루트 전체 재검증 대상이다. 옷과 색상은 판정 길이를 바꾸지 않는다.

## 몸통이 올라가는 원리

입력의 책임은 말단 목표를 만드는 데서 끝난다. 자세 계산기는 현재 고정된 손·발과 몸통 충돌 조건에서 가능한 골반 위치·회전을 찾는다.

1. 기존 골반 상태에서 중력과 제한된 자세 보정 가속도를 반영한 후보를 만든다.
2. 고정된 손에는 팔 길이·관절·접점 조건을, 지지 중인 발에는 다리 길이·압축 지지 조건을 적용한다.
3. 후보 중 선호 팔/다리 굽힘, 과도한 몸통 회전, 이전 자세에서의 큰 이동에 대한 비용이 작은 자세를 선택한다.
4. 새 목표로 속도 제한을 두어 이동하고, 각 반복에서 고정 접점을 다시 만족시키도록 투영한다.
5. 결과가 제약을 만족하는 경우에만 게임 상태로 확정한다.

목적함수는 선호 길이 오차 + 회전 비용 + 이전 자세 대비 이동 비용으로 구성한다. 가중치는 조정 데이터다. Y를 계속 높이는 보너스나 화면 위쪽으로 밀어주는 상시 상승력은 넣지 않는다. 접점이 그대로라면 목표 자세가 수렴하여 더 이상 올라가지 않아야 한다.

높은 발을 디딘 뒤 다리를 편하게 펴는 자세를 찾으면 골반이 올라간다. 높은 손을 잡으면 팔이 너무 펴진 불편한 자세를 줄이면서 몸통이 당겨진다. 모든 기존 접점과 충돌을 유지할 수 없으면 그 새 접점을 잡지 못한다. 이 원리가 재미있게 작동하는지는 G2 검증의 핵심이며 설계만으로 보장할 수 없다.

## 지지 모델

벽 위에서는 적어도 한 손이 고정되어 있어야 지지가 성립한다. 양발만으로 매달리는 것은 허용하지 않는다. 별도로 지정한 시작/휴식 플랫폼에서는 바닥 지지로 서 있을 수 있다.

손 접점은 매달림 지지를, 발 접점은 위로 받치는 압축 지지를 제공한다. 발판에는 벽면 내 지지 방향과 허용 각도 범위를 둔다. 그 방향으로 체중을 싣지 못하는 자세의 발은 시각적으로 가까워도 유효 지지 발로 세지 않는다. 발이 골반보다 높아서 발에 매달리는 형태는 지지에서 제외한다. 실제 접촉력 최적화의 완전한 해를 요구하지 않고, 지원 방향·상대 위치·제약 만족 여부로 분류한다.

지지 발 개수는 피로 분류에도 사용한다. 슬롯에 붙었다는 사실과 실제로 지지 중이라는 사실은 별도다. 발이 지지를 잃으면 HUD에서 이를 보여주고 피로를 다시 계산한다.

## 한 물리 틱의 순서

1. 입력 명령 수집: 취소/일시정지를 가장 먼저 처리한다.
2. 기존 상태의 스냅숏에서 의도적인 분리와 드래그 목표를 적용한다.
3. 정상 release의 새 잡기 후보를 계산한다.
4. 기존 접점을 우선 보존하면서 새 요청 조합을 평가한다. 최대 네 요청이므로 가능한 조합을 제한적으로 비교할 수 있다.
5. 양립 가능한 새 접점만 한 번에 확정한다. 거부된 말단은 Free다.
6. 몸통·말단 자세를 풀고, 지지 발과 피로를 갱신한다.
7. 피로가 0인 손을 분리하고 지지 상실 유예를 갱신한다.
8. 추락 여부를 판정한 뒤 정상 유지/체크포인트/기록을 갱신한다.
9. 검증된 자세 스냅숏을 렌더링·IK·사운드에 전달한다.

같은 틱에 두 손이 각각 가능한 홀드를 선택해도 두 접점의 조합이 불가능할 수 있다. 이때 개별 성공을 먼저 통보하지 않는다. 채택 조합은 신규 접점 수 최대 → 거리 합 최소 → 입력 순번 → 고정 limb ID로 고른다. 기존 슬롯 점유는 신규 요청보다 우선한다.

## IK와 표현

팔꿈치·무릎은 이전 프레임의 굽힘 방향과 리그의 pole 방향을 기준으로 계산해 관절이 갑자기 반대로 꺾이지 않게 한다. 도달 불가 목표는 가장 가까운 허용 위치로 제한하고 UI에 경계를 표시한다. 고정된 손발을 애니메이션이 끌어내지 못하도록 접촉 IK를 최종 우선으로 적용한다.

손가락은 붙기·떨어지기 포즈, 발은 발끝 접촉 각도, 몸통은 호흡·작은 흔들림만 추가한다. 화면 깊이 방향의 팔/다리 교차 보정은 시각 전용이며 도달 거리를 늘리지 않는다. MVP는 팔·다리끼리의 정밀 충돌을 생략하고, 몸통·머리와 벽 장애물·바닥 충돌만 처리한다.

### 피로 분류표

아래를 위에서부터 적용한다. 붙어 있는 손 각각에 같은 분류의 변화율을 적용한다. 단위는 1초당 점수다. Free 손은 +15로 회복하며 최대 100이다. 피로 소모가 꺼진 보조 모드에서는 감소만 0으로 대체한다.

| 조건 | 붙은 손의 변화율 |
| --- | --- |
| 시작/휴식 플랫폼 위 안정 자세 | +15 |
| 유효 지지 발 2개, 몸통 속도 0.10m/s 이하 | +10 |
| 유효 지지 발 2개, 이동 중 | -2 |
| 유효 지지 발 1개, 붙은 손 2개 | -3 |
| 유효 지지 발 1개, 붙은 손 1개 | -8 |
| 유효 지지 발 0개, 붙은 손 2개 | -15 |
| 유효 지지 발 0개, 붙은 손 1개 | -30 |

고정된 자세를 계속 유지하면 마지막 두 조건에서 가득 찬 손은 각각 약 6.7초·3.3초에 소진된다. 실제 게임에서 손발을 옮기면 조건이 바뀐다. 이 숫자로 난이도를 확정하지 않는다.

## 오류와 복구

- 불가능한 신규 접점은 거부한다. 이를 해결하려고 기존 팔다리를 강제로 늘리지 않는다.
- 정상 상태에서 수치 오류가 발생하면 해당 틱의 신규 동작을 되돌리고 직전 검증된 자세를 최대 한 틱 유지한다. 해당 틱의 게임 시간·피로 갱신도 확정하지 않는다.
- 3틱 연속 수치 오류면 자동 일시정지하고 진단 사유를 기록한다. 안전한 체크포인트 또는 루트 처음으로 재시작할 수 있게 한다. 사용자 실수로 기록하지 않는다.
- 이 복구는 손을 일부러 놓거나 피로가 소진된 정상 실패를 취소하는 용도로 사용하지 않는다.
- 위치·속도 상한, 유한수 검사, 슬롯 중복 점유 검사, 관절 길이 검사를 둔다. 잘못된 레벨 데이터는 플레이 전에 거부한다.

## G2 통과 과제

한 손 매달림, 양손 버티기, 높은 발로 일어서기, 대각선 한 손·한 발 이동, 좌우 교차, 같은 슬롯 경합, 새 접점 조합 불가, 전부 분리, 빠른 반복 입력, 카메라 추적, 30/60FPS에서 같은 시나리오를 확인한다. 지지점이 고정된 30초 동안 접점 오차가 0.02m를 넘지 않고 몸통이 계속 상승하지 않아야 한다.
