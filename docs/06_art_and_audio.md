# 06. 아트·사운드 디렉션

제작 수량은 [14](14_asset_manifest.md), 납품 묶음·포즈 검토·품질 비교·음원 규격은 [20. 아트 제작 의뢰서](20_art_production_brief.md)에 연결한다. 현재는 제작 기준을 작성하며 개발·기기 실행 캡처는 후속 범위다.

## 현재 판단의 한계

참고 이미지가 전달되지 않아 원본의 스타일·캐릭터 비율·색감·광원·재질·시점·해상도를 판독할 수 없다. “이와 유사한 이미지 퀄리티”는 유지해야 할 사용자 요구이며, 아래 내용은 **이미지 수령 전의 제작 기준 초안**이다. 와이어프레임을 최종 아트 시안으로 승인된 것처럼 사용하지 않는다.

잠정 방향은 깨끗한 실내 클라이밍 벽, 읽기 쉬운 캐릭터 실루엣, 명확한 홀드 색, 부드러운 명암의 3D 표현이다. 실사·카툰·페인터리·로우폴리 중 특정 스타일은 아직 확정하지 않는다.

## 참고 이미지가 오면 확정할 표

| 비교 축 | 기록할 내용 | 변경 영향 |
| --- | --- | --- |
| 구도 | 정면/후면, 원근, 카메라 각도, 캐릭터 화면 점유 | 카메라·입력 축·홀드 가시성 |
| 비율 | 머리 크기, 팔다리 길이, 손발 크기 | 리그·도달 거리·모든 루트 |
| 렌더 스타일 | 실사/일러스트, 외곽선, 면 분할 | 셰이더·조명·성능 |
| 색감 | 배경/캐릭터/홀드의 명도·채도 분리 | UI·색각 보조 |
| 재질 | 벽 거칠기, 홀드 표면, 옷 섬유 | 텍스처·재질 예산 |
| 빛 | 광원 수, 그림자 방향, 접촉 그림자 | 렌더러·품질 단계 |
| 디테일 | 얼굴·손가락·벽의 세부 표현 밀도 | 모델링 공수·화면 가독성 |
| 분위기 | 긴장/유쾌/차분함 | 애니메이션·사운드 |
| 출처 | 사용자 제공/URL, 제작자, 사용 가능 범위 | 원본 보관·배포 가능 여부 |

참고 이미지의 로고·캐릭터·텍스처를 그대로 재사용하는 대신, 비교 기준을 추출해 이 프로젝트에 맞는 자산을 만든다. 실제 게임에 쓸 자산의 제작자·출처·라이선스는 에셋 목록에 기록한다. 이는 특정 이미지의 권리를 판단한 결과가 아니라 제작 운영 규칙이다.

## 품질을 확보하는 순서

1. 참고 이미지의 동일한 화면 비율·구도에서 캐릭터 1종, 벽 한 부분, 홀드 세트, 기본 HUD로 한 장면을 만든다.
2. 엔진 안에서 목표 기기 해상도로 캡처한다. 콘셉트 이미지의 품질과 실행 화면의 품질을 혼동하지 않는다.
3. 정지 화면에서 실루엣, 접촉 그림자, 재질, UI 조화를 비교한다.
4. 움직이는 영상에서 손발 밀림, 관절 꺾임, 옷 관통, 떨림, 그림자 깜빡임을 확인한다.
5. 사용자가 참고 이미지와 비교할 수 있는 상태에서 방향을 확정한 뒤 전체 에셋으로 확장한다.

아트 본작업 이전에 필요한 입력은 참고 이미지다. 이를 기다리는 동안 조작·데이터·구조 설계는 계속 가능하다. 외형 확정 없이 대량 캐릭터·의상 제작에 들어가지 않는다.

## 캐릭터와 리깅

| 항목 | 제작 기준 |
| --- | --- |
| 방향 | 등을 보는 기본 시점, 얼굴은 필수 가독 요소가 아님 |
| 체형 | 1종 고정. 팔/다리 길이는 04 문서와 맞춘다 |
| 메시 | 관절 굽힘에 필요한 토폴로지, 팔꿈치·무릎·어깨 변형 우선 |
| 리그 | 골반, 척추, 목, 머리, 좌우 어깨·팔·손, 좌우 다리·발 |
| 손 | 기능상 손가락 개별 물리는 없음. 잡기/펴기 포즈 사용 |
| 발 | 발끝 접촉 회전과 신발 외형, 접점이 표면에 닿아 보이도록 정렬 |
| 의상 | 기본 의상 1개, 헐렁한 천 물리 없음, 색상 3변형 |
| 애니메이션 | 대기·접촉·힘주기·피로·추락·완등, IK와 분리된 보조 움직임 |

팔 길이나 손 크기는 보기 좋은 비율만으로 결정하지 않는다. 캐릭터가 화면에 작게 나왔을 때도 손·발과 홀드가 구분되어야 한다. 넓게 벌린 자세, 교차 자세, 한 손 매달림을 리그 납품 검수 포즈로 사용한다.

## 벽·홀드·조명

벽은 모듈 단위로 제작하고 접합선·반복 무늬를 줄인다. 장식 요소는 실제로 잡을 수 있는 홀드와 다른 형상·명도 체계를 쓴다. 손용·발용·공용·정상 홀드는 색 외에 형태 또는 작은 표식으로 구분한다. 표면의 시각적 잡기 위치와 데이터 슬롯 중심이 일치해야 한다.

기본 광원 1개, 환경광, 절제된 접촉 그림자를 기준으로 시작한다. 고가의 실시간 전역 조명·후처리를 품질의 전제로 삼지 않는다. 그림자 해상도와 실내 벽의 베이크 조명 사용 여부는 한 장면 성능 측정 후 결정한다. 저사양 단계에서는 장식·그림자·파티클을 줄여도 홀드와 상태 표시를 유지한다.

## 초기 에셋·렌더 예산

아래는 기술 검증을 위한 예산 가설이다. 참고 이미지가 요구하는 품질에 따라 변경할 수 있지만 실제 기기 프레임 예산과 함께 결정한다.

| 항목 | 시작 예산 |
| --- | --- |
| 캐릭터 | 화면 내 1명, 15k~25k 삼각형, 변형 뼈 40개 이하 |
| 홀드 | 원형 메시 8종 이내, 하나당 300~1,500 삼각형, 인스턴싱 고려 |
| 캐릭터 텍스처 | 주요 맵 1K~2K, 재질 슬롯 3개 이하 |
| 벽 텍스처 | 재사용 2K 세트 중심, 루트마다 별도 대형 맵 생성 지양 |
| 전체 화면 | 150k 삼각형, 120 draw call 이내를 초기 목표로 계측 |
| 파티클 | 동시 80개 이하, 과도한 투명 중첩 금지 |
| 텍스처 메모리 | GPU 리소스 약 128MiB 이내 목표, 측정 방식 별도 기록 |

삼각형·draw call만으로 성능을 판단하지 않는다. 화면 픽셀 수, 투명도, 그림자, 텍스처, 셰이더 복잡도와 발열을 함께 측정한다. 최종 합격 조건은 [검증 계획](10_validation.md)이다.

## 사운드와 진동

| 사건 | 소리 | 진동 제안 |
| --- | --- | --- |
| 손 잡기 | 짧은 마찰·접촉, 3변형 | 15~25ms 가벼운 펄스 |
| 발 디딤 | 낮은 접촉, 3변형 | MVP에서 꺼짐 |
| 손 미끄러짐 | 짧은 마찰 | 40ms 1회 |
| 피로 경고 | 방해하지 않는 짧은 신호 | 최대 초당 1회, 설정 가능 |
| 추락 | 짧은 이동음·매트 착지 | 60ms 이하 1회 |
| 완등 | 1초 안팎 확인음 | 짧은 2회 펄스 |
| UI | 선택·확인·거부 | MVP에서 꺼짐 |

물리 판정 결과 이벤트만 사운드를 발생시킨다. 후보 표시만으로 잡기 소리를 재생하지 않는다. 같은 틱의 여러 접촉은 음량을 합산 폭주시키지 않도록 제한한다. 하드웨어에 따라 진동 강도·길이 체감이 달라질 수 있으므로 실제 기기에서 조정한다.

배경음은 반복 가능한 차분한 1곡, 환경음은 실내 1종으로 시작한다. 음악을 꺼도 플레이 정보가 사라지지 않는다. 음원은 자체 제작 또는 사용 권리가 확인된 자산을 사용하고 출처를 기록한다.

## 제작·납품 흐름

콘셉트/비율표 → 모델·UV → 재질 → 리그 → 극단 자세 검수 → glTF/GLB 내보내기 → 엔진 재질·조명 확인 → 실제 기기 캡처 → 비교·수정 순서로 진행한다. 원본 편집 파일과 엔진용 산출물을 구분하고 재생성 방법·버전을 남긴다. 이미지 생성 결과는 콘셉트 참고가 될 수 있으나 곧바로 리깅 가능한 3D 모델이나 최종 실행 화면이 되지는 않는다.

## 아트 수락 기준

- 참고 이미지에 대한 구도·스타일 비교표가 채워져 있고 사용자 검토가 끝났다.
- 같은 해상도에서 캐릭터·홀드·UI의 완성도를 나란히 비교할 수 있다.
- 접점 20개 검수 포즈에서 명백한 손발 부유·벽 관통·역관절이 없다.
- 움직이는 장면 30초에서 접촉 밀림과 반복적인 떨림이 없다.
- UI를 모두 표시하고 네 손가락을 올린 상태에서도 다음 홀드가 보인다.
- 목표 기기 성능을 만족하거나 품질 단계별 차이를 구체적으로 기록했다.

현재 위 조건의 실행 결과는 없다.
