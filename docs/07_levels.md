# 07. 레벨·콘텐츠 설계

## 콘텐츠 범위

MVP는 **튜토리얼 T01~T03 + 일반 루트 R01~R09, 총 12개**다. 하나의 실내 클라이밍 시설과 벽 모듈을 재사용하되 홀드 배치와 동선으로 다양성을 만든다. 모든 길이·시간·배치는 제작 초안이며 실제 완등 검증 전이다.

| ID | 이름 | 학습/도전 요소 | 높이 초안 | 예상 첫 시도 | 체크포인트 |
| --- | --- | --- | --- | --- | --- |
| T01 | 첫 손잡이 | 패드 선택, 이동, 놓아서 잡기, 터치 없는 유지 | 2~3m | 안내 포함 1~3분 | 단계별 |
| T02 | 발을 올려요 | 양발 이동, 몸통 상승, 팔 회복 | 3~4m | 1~2분 | 단계별 |
| T03 | 함께 움직이기 | 대각선 2말단 동시 입력, 지지 상실, 양손 완등 | 3~4m | 1~2분 | 단계별 |
| R01 | 첫 번째 벽 | 짧은 직선 상승, 기본 순서 반복 | 4.2m | 45~60초 | 없음 |
| R02 | 지그재그 | 좌우 경로 읽기, 가까운 발 이동 | 6m | 45~75초 | 없음 |
| R03 | 높게 딛기 | 높은 발판을 먼저 써서 다음 손 도달 | 6m | 60~90초 | 없음 |
| R04 | 옆으로 한 걸음 | 수평 이동과 몸통 기울기 | 7m | 60~90초 | 없음 |
| R05 | 잠깐 버티기 | 한 손 버티기, 손 피로 확인 | 7m | 60~90초 | 없음 |
| R06 | 쉬어가는 길 | 안정 자세·플랫폼 회복·복귀 | 10m | 75~120초 | 중간 1개 |
| R07 | 교차하는 길 | 손 교차, 반대쪽 발 이동 순서 | 8m | 60~100초 | 없음 |
| R08 | 좁은 선택 | 후보가 가까운 홀드, 계획적인 순서 | 9m | 75~120초 | 없음 |
| R09 | 마지막 루트 | 기존 요소 조합, 긴 경로의 페이스 조절 | 12m | 90~120초 | 중간 1개 |

R01은 튜토리얼을 마치거나 건너뛰면 열린다. R02 이후는 직전 일반 루트 완등으로 열린다. 튜토리얼은 언제든 플레이 가능하다. 무작위 생성·실시간 움직이는 홀드·부서지는 홀드는 이 범위에 포함하지 않는다.

## 홀드 문법

| 유형 | 목적 | 제작 제한 |
| --- | --- | --- |
| 큰 손홀드 | 기본 잡기, 다음 이동의 기준 | 단일 손 슬롯, 넉넉한 시각적 면적 |
| 작은 손홀드 | 후보 선택 정밀도 | 판정 반경과 외형을 설명 가능하게 맞춤 |
| 발판 | 골반 위치와 피로 관리 | 발 슬롯, 유효 지지 방향 포함 |
| 공용 홀드 | 손·발 동선 결합 | 슬롯 종류/위치를 명확히 분리 |
| 정상 홀드 | 종료 조건 | 좌·우 구분 없는 손 슬롯 2개, 동시 도달 가능 |
| 플랫폼 | 시작·휴식·체크포인트 | 실제 바닥 지지 구역, 단순 홀드와 구분 |

형태의 다양성과 물리 규칙의 다양성을 혼동하지 않는다. 첫 버전은 외형이 다른 손홀드라도 피로 규칙이 같다. 미끄러운 재질·단방향 손홀드 등 신규 규칙은 별도 확장이다.

## 배치 원칙

- 한 구간에서는 새 도전 요소를 한 가지씩 소개한다.
- 손홀드 사이 거리만으로 도달성을 판단하지 않는다. 당시 골반·어깨·기존 손발 접점이 모두 가능한지 검사한다.
- 전진하기 위해 기존 손을 먼저 모두 놓아야 하는 루트는 만들지 않는다. 점프와 공중 재잡기는 MVP에 없다.
- 다음 목표는 카메라 중앙 가시영역에서 확인 가능해야 한다. 패드 밑에 핵심 홀드를 숨기지 않는다.
- 최소 한 가지 의도된 완등 경로를 기록하고, 다른 풀이도 막지 않는다.
- 시간이 부족해서 실패하는 것과 물리적으로 불가능한 배치를 구분한다.
- 원근으로 보이는 거리와 실제 평면 판정 거리가 크게 어긋나지 않게 한다.
- 체크포인트 진입/복귀 자세는 해당 콘텐츠 버전에서 다시 검증한다.

## R01 좌표 초안

단위 m, X 오른쪽/Y 위, 벽 원점은 바닥 중앙이다. 루트 작성 범위 X=-1.5~1.5, Y=0~4.2. 골반 초기 위치 (0, 0.95), 몸통 회전 0°, 손 피로 각각 100. H01/H02/F01/F02를 초기 접점으로 한다.

| 홀드 ID | 슬롯 | X | Y | 허용 |
| --- | --- | --- | --- | --- |
| H01 | hand_1 | -0.45 | 1.80 | 손 1개 |
| H02 | hand_1 | 0.45 | 1.80 | 손 1개 |
| F01 | foot_1 | -0.30 | 0.10 | 발 1개 |
| F02 | foot_1 | 0.30 | 0.10 | 발 1개 |
| H03 | hand_1 | -0.50 | 2.10 | 손 1개 |
| H04 | hand_1 | 0.50 | 2.10 | 손 1개 |
| F03 | foot_1 | -0.35 | 0.65 | 발 1개 |
| F04 | foot_1 | 0.35 | 0.65 | 발 1개 |
| H05 | hand_1 | -0.40 | 2.55 | 손 1개 |
| H06 | hand_1 | 0.40 | 2.55 | 손 1개 |
| F05 | foot_1 | -0.25 | 1.15 | 발 1개 |
| F06 | foot_1 | 0.25 | 1.15 | 발 1개 |
| G01 | goal_left | -0.22 | 3.00 | 손 1개 |
| G01 | goal_right | 0.22 | 3.00 | 손 1개 |

홀드 오브젝트 13개, 슬롯 14개다. 정상은 하나의 큰 홀드가 두 슬롯을 가진다. 시작 플랫폼 바닥과 캐릭터의 초기 발 접촉 높이를 일치시킨다.

의도한 이동 순서는 LH→H03, RH→H04, LF→F03, RF→F04, LH→H05, RH→H06, LF→F05, RF→F06, LH/RH→G01의 두 슬롯이다. 이는 **저작용 경로 가설**이다. 각 단계의 자세 계산, 발 지지, 피로, 동시 입력 가능성을 실제 프로토타입에서 확인하기 전에는 완등 가능한 레벨로 판정하지 않는다.

## 루트 저작 정보

각 루트는 이름, 학습 요소, 난이도, 영역, 시작 자세, 홀드·슬롯, 카메라 경계, 실패선, 정상 조건, 체크포인트, 시간 메달 기준, 의도 경로, 검증 상태를 가진다. 데이터 구조는 [09](09_data_and_save.md)에 정의한다.

제작 상태는 Draft → GeometryChecked → Played → Tuned → Ready다. 정적 거리 검사만 한 경우 GeometryChecked를 넘어갈 수 없다. Ready는 지정 기기에서 완등 영상과 주요 검증 항목이 있는 상태다. 이번 문서의 모든 루트는 Draft다.

## 제작 검증

1. 슬롯 ID 중복·잘못된 참조·벽 바깥 배치·시작/정상 누락을 자동 확인할 계획이다.
2. 초기 자세와 체크포인트의 길이·관절·슬롯·충돌 조건을 검증한다.
3. 의도 경로를 한 동작씩 따라가며 도달 가능한지 확인한다.
4. 일반/보조, 30/60FPS에서 성공·실패가 설명 가능한지 관찰한다.
5. 신규 사용자에게 시연하지 않고 풀게 해 막히는 위치를 기록한다.
6. 가시성·소요 시간·피로를 조정하고 콘텐츠 버전을 올린다.

홀드 연결 그래프가 존재한다는 것만으로 실제 캐릭터가 이동할 수 있다고 보지 않는다. 여러 접점을 동시에 유지하는 자세 공간이 제약이므로 직접 플레이 검증이 필요하다.

## 확장 후보

첫 제품 이후 야외 암벽·채석장 등의 새 테마, 30개 내외 루트팩, 고정 규칙의 주간 챌린지, 기록 리플레이를 검토할 수 있다. 아직 일정·서버·에셋 제작 범위에 포함하지 않는다. 새 체형과 점프는 기존 전체 루트에 영향을 주므로 테마 추가와 별도 프로젝트로 평가한다.
