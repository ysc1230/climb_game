# 12. 결정·가정·위험 관리

## 상태 정의

- 확정 요구: 사용자가 명시한 조건.
- 제안 채택: 이번 문서를 일관되게 작성하기 위해 선택한 기본안. 사용자 최종 확정이나 구현 증거가 아니다.
- 미결정: 정보·비교·실험 결과가 필요함.
- 검증 완료: 지정 증거가 있는 항목. 현재 게임 기능에는 해당 항목이 없다.

## 대안과 선택 기준

가로 네 패드가 편하지 않다면 먼저 크기·위치·기기 자세를 조정한다. 그 다음 손/발 패드의 수직 간격이나 대각 배치를 비교한다. 두 엄지 전용으로 자동 전환하여 원래 네 손가락 요구를 충족했다고 처리하지 않는다.

몸통 이동을 플레이어가 더 직접 제어해야 한다는 결과가 나오면, 붙어 있는 손발을 이용하는 별도의 몸 당기기 제스처를 연구할 수 있다. 그러나 분리 드래그와 충돌할 수 있으므로 MVP 규칙에 조용히 섞지 않고 D04/D07을 다시 설계한다.

REF01은 입체 공간에 일러스트풍 선·명암이 보이는 장면으로 분석했다. v0.5는 아트 방향을 유지하면서 XY 입력에 제한된 3D 자세 검증을 추가한다. 다른 참고나 실제 플레이 요구가 추가되어 자유 3D 이동이 필요해지면 판정 가정을 다시 검토한다. 현재 정지 화면만으로 원작의 기술 구조나 미제작 아트의 일치 수준을 확약하지 않는다.

## 이번 설계의 완료 범위

게임 목표, 조작 상태, 자세 모델, 화면, 아트 제작 기준, 12개 콘텐츠 초안, 데이터·저장, 검증·개발 순서가 문서화되어 있다. 미완료 항목은 참고 이미지와의 실제 비교, 네 손가락 사용성·물리·성능 검증, 코드 구현, 빌드, 배포다. 문서 완성과 제품 완성을 구분한다.

v0.2의 발견 사항과 수정 위치는 [설계 검토 기록](17_design_review_v0_2.md)에 정리했다. 모호했던 규칙을 문서로 정한 상태이며 게임 검증까지 끝난 상태는 아니다.

v0.3의 [설계 인계 기록](21_design_readiness_v0_3.md)은 화면·설정·저작·아트 의뢰의 완료 범위와 후속 개발/실행 작업을 구분한다. v0.4에서는 [REF01 분석과 제작 방향](22_reference_art_direction.md)을 반영했다. 남은 것은 우리 제작물의 비교와 기기 측정이며 현재 문서 작업을 막는 승인 조건으로 쓰지 않는다.
