# 17. 설계 검토·구체화 기록 v0.2

검토일: 2026-10-30(KST) · 대상: v0.1 기획·설계 · 구현 전

사용자의 “구체화가 필요한 항목을 구체화” 요청에 따라 기존 문서에서 구현자가 임의로 해석해야 하는 규칙과 서로 충돌할 수 있는 조건을 보완했다. **게임 코드는 작성하지 않았다.** 아래의 “정리”는 문서 결정이며 실행 검증 완료가 아니다.

## 현재도 남겨둔 항목

| 항목 | 미확정인 이유 | 해소할 작업 |
| --- | --- | --- |
| 참고 이미지와의 유사도 | 실제 이미지 없음 | 동일 구도·크기의 대표 장면 비교 |
| 네 손가락의 편안함 | 실제 기기·손 크기 차이 | G1 테스트 |
| 자세 해법의 재미·안정성·속도 | 해법을 실행하지 않음 | G2 프로토타입과 계측 |
| 나머지 루트의 전체 슬롯 좌표 | 자세 해법과 경로 검증 필요 | 구간별 저작 후 Draft→Ready 절차 |
| 최소 기기·렌더러·최종 공수 | 실행 성능과 아트 복잡도 미확인 | G3/G5 결과 반영 |

이 항목들은 문장이나 임의 숫자를 더 넣는 것으로 해결되지 않는다. 사용자 자료 또는 구현 후 측정이 필요한 부분으로 남긴다. 코드 개발은 사용자가 시작을 요청한 다음 수행한다.

## 이번 검수의 범위

문서 링크·필수 문서 존재·스테이지 ID·중복 테스트 ID·수치 계산·문서 간 참조를 확인한다. 변경 파일은 Markdown 설계·설명 문서로 한정한다. 기존 화면 배치도는 구조 검토용으로 유지하며 정밀한 배치·시야 값은 v0.2의 05 문서를 따른다.

실제 게임 플레이·멀티터치·프레임·세이브 중단 시험은 실행하지 않았다. 문서의 경계 시험 20개는 개발 후 수행할 명세다.

정적 문서 검수에서 문서 20개와 기존 SVG 1개, 내부 링크 86개, 12개 스테이지 카드, DT01~DT20의 고유 ID를 확인했다. 60Hz 기준 시간 환산·데드존 변환·무릎 제한에 따른 최소 거리 계산도 대조했다. 깨진 내부 링크나 게임 소스 파일은 발견되지 않았다.
