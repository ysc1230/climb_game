# 20. 아트·사운드 제작 의뢰서

설계 v0.5 연계 · 2026-10-31 · REF01 방향 유지, CH01 기존 제작 기록은 23 참조

이 문서는 제작자가 무엇을 제출하고 무엇으로 검토받을지 정한 의뢰서다. 수량은 [14. 에셋 목록](14_asset_manifest.md), 품질·성능 예산은 [06. 아트·사운드](06_art_and_audio.md)를 따른다. 사용자 제공 REF01은 [22. 참고 분석](22_reference_art_direction.md)에 반영했다. 현재 납품물은 제작 명세이며 3D 모델·음원·게임 캡처가 아니므로 참고와 같은 완성도를 달성했다고 평가하지 않는다.

## 의뢰 목적과 유지할 조건

목표는 등을 보는 캐릭터가 손·발로 홀드를 짚는 모습을 작은 모바일 화면에서도 명확하게 읽게 하는 것이다. 캐릭터 1종, 기본 의상 1세트, 색상 총 3개, 실내 클라이밍 공간 1테마를 만든다. 도달 거리·팔다리 길이·홀드의 실제 접점은 외형 제작 중 임의 변경하지 않는다.

고정된 요구는 네 팔다리 구분, 손/발과 홀드의 접촉, 정상 두 슬롯의 가독성, 중앙 시야와 측면 패드의 분리다. REF01을 바탕으로 얇은 윤곽선·일러스트풍 명암·무광 재질·따뜻한 흙빛 팔레트를 기본 방향으로 삼는다. 독자적 긴팔 등반복·암벽화·작은 초크백과 색상 3종을 22의 시작안으로 제작한다. 최종 실루엣·선 두께·색 조합은 실제 제작물 비교에서 정한다.

## 캐릭터·리그 납품 규칙

- 판정상의 팔 0.40+0.38m, 다리 0.52+0.48m와 관절 위치는 04를 기준으로 한다. 외형 비례를 바꿔야 하면 모델만 수정하지 않고 설계 변경 항목으로 올린다.
- 손바닥 접점, 발 앞부분 접점, 손목/발목 축, 팔꿈치/무릎의 굽힘 방향을 원본에 표시하고 문서로 제공한다. 메시 원점과 판정 골반 원점의 관계를 적는다.
- 원본에는 단위·축·rest pose·뼈 이름·가중치·텍스처를 보존한다. 최종 뼈 수 40개 이하, 캐릭터 15k~25k 삼각형, 재질 슬롯 3개 이하를 초기 제작 예산으로 사용한다.
- 게임 접점은 IK가 제어한다. 보조 애니메이션이 몸통을 벽 밖으로 옮기거나 붙잡은 손발을 미끄러뜨리지 않게 한다. 별도 점프·등반 모션 라이브러리를 납품 범위에 추가하지 않는다.
- 손은 펴기/잡기 두 기본 포즈, 보조 애니메이션은 대기/힘주기/피로/추락/완등 다섯 종류다. 아래 검토 포즈 20개는 추가 애니메이션 20클립을 뜻하지 않는다.

## 환경·홀드·UI

벽 모듈 3개는 동일한 단위·접합 원점을 사용한다. 시작/휴식 플랫폼 2종은 발 접촉면의 높이와 지지 영역을 표시한다. 배경 장식에는 홀드와 혼동되는 실선 링이나 손잡이 모양을 반복하지 않는다. 하나의 루트가 길어져도 새로운 고해상도 벽 텍스처를 매번 만들지 않는다.

홀드 메시 8종은 큰 손홀드 3, 작은 손홀드 1, 발판 2, 공용 1, 정상 1이다. HD01의 변형은 HD01_01~03, HD03은 HD03_01~02로 구별한다. 손·발·공용·정상은 색을 보지 않아도 형상이나 표식으로 구분해야 한다. 외형의 크기와 후보 반경은 서로 다른 값이며 크게 그렸다고 멀리 잡히지 않는다.

공용 홀드는 손/발 접점 위치를 따로 제공한다. 정상 홀드는 좌우 두 손 접점이 겹치지 않는 시각적 크기로 만든다. 표면 중심·슬롯 앵커·장식의 구분을 보여주는 제작용 도면을 원본과 함께 전달한다.

UI01 아이콘은 손/발, 왼쪽/오른쪽, 피로, 후보, 거리 부족, 점유, 실패를 담는다. UI02는 기본/눌림/선택/비활성/경고 상태, UI03은 잠금/해금/완등과 일반/보조/복구 기록 표현을 갖춘다. 필수 상태는 색만 바꾸지 않고 모양·테두리·텍스트를 함께 사용한다. UI 상태와 문구는 [18](18_screen_spec.md)를 따른다.

기존 와이어프레임의 민트·보라·노랑은 배치 설명용이다. 이를 사용자가 선택한 브랜드 팔레트로 간주하지 않는다. 실제 배색을 정할 때 캐릭터, 잡을 홀드, 후보 링, 장식 배경 사이의 구분을 확인한다.

## 음원 납품 의뢰

| 묶음 | 수량·길이 초안 | 들려야 하는 차이 |
| --- | --- | --- |
| AU01 손 접촉 | 3클립, 각 0.1~0.4초 | 짧은 마찰·손바닥 접촉, 반복 피로 최소 |
| AU02 발 접촉 | 3클립, 각 0.1~0.4초 | 손보다 낮고 단단한 디딤 |
| AU03 상태 | 미끄러짐/경고/추락/완등 각 1, 0.1~1.2초 | 원인을 구분, 완등은 약 1초 |
| AU04 UI | 선택/확인/거부 각 1, 0.05~0.25초 | 게임 접촉과 혼동되지 않는 짧은 피드백 |
| AU05 반복음 | BGM 1곡 60~90초, 실내 환경음 1개 30~60초 | 자연스러운 루프, 핵심 효과음 가림 없음 |

편집 원본 WAV 48kHz/24bit를 초기 납품 규격으로 제안한다. 효과음은 모노, BGM/환경음은 스테레오를 기본으로 하되 엔진 압축·임포트 설정은 후속 통합에서 정한다. 클리핑·루프 경계 잡음·불필요한 앞뒤 무음을 제거하고 루프 지점을 기록한다. 장치 스피커와 실제 믹스에서의 크기는 아직 평가하지 않았다.

접촉음은 후보가 아니라 확정된 GripAccepted에서 재생한다. 같은 틱 접촉 여러 개의 음량 폭주를 제한하고 경고는 최대 초당 1회다. 진동 길이·종류는 06, 기본 켜짐/꺼짐과 음량은 18을 따른다. 음원을 재생하지 않아도 필요한 상태 정보를 읽을 수 있어야 한다.

## 파일·인계·수정 규칙

납품 파일 이름은 asset_id, 변형, 버전을 구별한다. 예시는 CH01_v001, HD01_02_v001이다. 실제 경로는 제작 시작 때 정하며 존재하지 않는 파일을 원본 목록에 올리지 않는다. 편집 원본·GLB·텍스처·미리보기·설명은 같은 버전을 추적할 수 있어야 한다.

각 항목에는 제작자, 출처, 이용 조건, 원본 편집/수정/배포 가능 범위, 도구 버전, 단위·축, 사용 예산, 미해결 사항을 기록한다. 엔진 캐시·빌드·서명 자료는 납품 원본에서 제외한다. 대용량 관리 방식은 실제 크기 확인 후 정한다.

수정 요청은 “더 예쁘게” 대신 대상 ID·포즈/화면·관찰된 차이·유지할 판정 기준을 적는다. 색상 수정과 슬롯 위치 수정은 영향이 다르다. 슬롯이나 체형이 바뀌면 해당 콘텐츠 버전과 레벨 검수 범위까지 함께 재검토한다.

현재 모든 게임 에셋은 Brief 단계다. Accepted/Integrated와 실행 검수 칸은 비워 둔다. 제작물 전달, 참고 이미지와의 외형 비교, 실제 기기에서의 품질·성능 확인을 각각 별도 완료 조건으로 관리한다.
