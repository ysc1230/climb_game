# 21. v0.3 설계 인계·범위 기록

2026-10-30 · 문서 작업 완료 범위와 후속 작업의 구분

이 문서는 v0.3 당시의 검토 기록이다. 이후 사용자 참고 이미지 REF01을 수신·분석했으며, 최신 아트 방향과 현재 참고 상태는 [v0.4 참고 분석](22_reference_art_direction.md)을 따른다. 아래 당시의 “참고 없음”과 파일·링크 수는 이력으로 보존한다.

사용자의 “개발 및 기기 실행검증은 제외하고 진행” 요청을 반영한다. 현재 작업의 완료 조건은 **게임을 구현하지 않고도 정할 수 있는 동작·콘텐츠·화면·제작 규약을 일관된 문서로 인계하는 것**이다. 기기 시험이나 프로토타입 통과를 이번 문서 작업의 종료 조건으로 요구하지 않는다.

v0.2의 입력·자세·복구·기록·12개 스테이지 규칙은 유지한다. v0.3은 제품 기능 수를 늘리기보다 화면에서 그 규칙을 어떻게 보여주고 제작자가 어떻게 인계받을지 정한다. 시작 준비, 설정, 정보용 최고 도달 높이에 필요한 데이터 필드는 관련 기준 문서와 함께 맞춘다.

## 현재 범위와 제외 범위

| 구분 | 포함되는 일 | 상태 |
| --- | --- | --- |
| 현재 완료 대상 | 기획, 동작 명세, 데이터 필드, 제작 요구사항, 후속 검증 계획 | 문서화 |
| 현재 문서 검수 | 로컬 링크·파일 유형·요구사항·수치·문서 간 충돌 확인 | 아래 결과 기록 |
| 참고 입력 후 결정 | 실제 이미지 분석, 외형·색·조명 비교, 최종 아트 방향 | 참고 이미지 없음 |
| 후속 개발 | 엔진 프로젝트, 게임 소스, 실행 레벨 데이터, UI 구현, 프로토타입, 빌드·CI | 이번 범위 제외 |
| 후속 실행 검증 | 에디터·에뮬레이터·실기기 플레이, 멀티터치, 완등, 저장 복구, 성능·발열 | 이번 범위 제외·미실행 |
| 후속 제작/출시 | 실제 3D·음원 자산, 엔진 통합, 아이콘·스토어 제출 | 제작 규약만 준비 |

10의 G1~G5와 11의 M1~M6는 향후 개발 순서다. 현재 사용자에게 실행 승인을 요구하거나 문서 작업을 중단하기 위한 조건이 아니다. 미검증 수치와 Draft 루트를 임의로 “통과” 처리하지 않는다.

## 현재 남아 있는 판단

| 항목 | 현재 설계에서 사용하는 가정 | 결정을 바꿀 증거 | 현재 처리 |
| --- | --- | --- | --- |
| 이미지 품질 | 읽기 쉬운 실내 3D, 최종 스타일 미정 | 실제 참고 이미지와 비교 자료 | 제작 기준만 완성 |
| 네 손가락 편안함 | 기기를 놓고 사용, 네 패드 조절 | 이후 실제 사용자·기기 관찰 | 사용성 합격 주장 없음 |
| 자세 해법·루트 재미 | 제약 몸통·IK, 12개 Draft 루트 | 이후 완등·실패·반복 플레이 | 수치·의도 경로만 제안 |
| 지원 기기·렌더러 | Android 우선, 엔진 선택 제안 | 이후 최소 기기·GPU 실측 | 지원 목록 확정 안 함 |
| 개발 기간 | 41~60 작업일 초안 | 구현 속도·아트 복잡도 | 약속된 납기 아님 |
| 브랜드·가격 | 작업명, 광고·결제 없는 MVP | 별도 출시 방향 | 신규 유료 기능 설계 안 함 |

각 항목은 외부 입력 또는 현재 제외된 작업의 결과가 필요한 사안이다. 문장이나 수치를 더 채운다고 실측을 대신할 수 없으므로 가정을 남기고 설계 인계를 마친다.

## 문서 검수 기록

이 절에는 이번 변경의 정적 검수만 기록한다. 게임 실행·자동 게임 테스트·사용자 테스트 결과는 없다.

- 파일 유형: Markdown과 설계 SVG만 허용. 게임 소스·엔진 프로젝트·실행 콘텐츠·빌드 산출물 부재를 확인한다.
- 링크: 저장소 내부 상대 링크가 실제 파일을 가리키는지 확인한다. 외부 웹 링크의 최신성 재조사는 이번 문서 변경에 포함하지 않는다.
- 수치: 시작 자세 거리/각도, 60Hz 시간 환산, 8개 홀드 메시·13개 효과음·2개 반복음, 이미지 비교 가중치 합계 100을 확인한다.
- 일관성: 보조 누적과 복구 기록, 시작/재개 준비, CP 재시도와 새 시도, 설정 초기화와 진행 초기화를 구분한다.
- 전체 콘텐츠: 3튜토리얼+9루트가 유지되고 모두 Draft임을 확인한다.

| 검수 항목 | 결과 | 한계 |
| --- | --- | --- |
| 파일 구성 | Markdown 24개 + 기존 SVG 1개, 총 25개 | 게임 소스·프로젝트·빌드 없음 |
| 내부 상대 링크 | 125개 확인, 깨진 링크 0개 | 외부 공식 자료를 새로 검증한 결과는 아님 |
| 문서 구조 | Markdown 표 열 수·코드 펜스, SVG XML 구조 확인 | 실제 UI 화면 렌더링을 검증한 것은 아님 |
| 식별자 | 12개 스테이지, P01~P20, 기존 DT01~DT20의 누락·중복 없음 | 스테이지는 Draft, DT는 미실행 시험 명세 |
| 산술 | 시작/CP 거리·각도, 9/36틱, R01 2,400틱, 에셋 수량·가중치 확인 | 자세 수렴·충돌·동적 완등 가능성은 미검증 |
| 동작 일관성 | 시작/CP 준비를 15에 반영, 홈 이탈 확인·도달 높이·보조 적용·색상 저장 연결 | 실제 사용자·기기 동작 결과 아님 |

검수 중 일시정지 화면의 “재시작만 확인” 표현을 홈/목록 이탈에도 확인하도록 맞췄다. 정의되지 않았던 HUD 진행률은 계산 근거가 있는 도달 높이로 정리했고, 발/메뉴 진동은 MVP에서 끄는 기본안으로 통일했다. 해금 색상의 선택·저장과 진행 초기화 시 기본색 복귀도 연결했다.

## 다음 작업의 출발점

문서만 더 수정하는 경우 해당 분야의 기준 문서에서 시작한다. 실제 참고 이미지가 제공되면 06/20의 비교표를 먼저 채워 아트 방향을 구체화할 수 있다. 이후 사용자가 개발을 요청하면 [개발 인수인계](../DEVELOPMENT_HANDOFF.md)의 작은 입력 검증 범위부터 진행한다. 현재 단계에서는 개발이나 기기 실행을 시작하지 않는다.
