## 캐릭터 제작 방향

기본 외형은 몸에 맞는 긴팔 상의, 발목 길이의 클라이밍 바지, 암벽화, 작은 초크백을 가진 독자적인 성인 등반자 1종으로 제안한다. 청록 상의와 낮은 채도의 베이지/갈색 하의를 시작안으로 둔다. 이미지 속 인물의 얼굴·특정 장비 배치·붕대 무늬를 그대로 복제하지 않는다.

외형을 꾸미면서 손·발을 감추는 큰 가방이나 넓은 장식을 추가하지 않는다. 중요한 선은 어깨·팔꿈치·손목·골반·무릎·발목의 방향을 읽게 해야 한다. 옷의 촘촘한 선을 실루엣보다 진하게 만들지 않는다. 머리 크기와 얼굴 상세는 뒷모습 가독성을 확인할 수 있는 시안에서 결정한다.

판정용 팔 0.40+0.38m, 다리 0.52+0.48m와 접점은 [04](04_pose_and_physics.md)를 유지한다. 참고 이미지 인물의 키·관절 길이는 측정값으로 사용하지 않는다. 20의 P01~P20 포즈에서 선이 겹쳐 손발이 사라지거나 옷이 관절을 가리는지 확인할 계획이다.

색상 3종은 기존 CH04_01~03 안에서 재질 색만 바꾼다. 기본은 청록, 해금색은 적갈색/밝은 아이보리 계열을 제안하되 후보 링·벽과의 구분을 보고 조정한다. 해금 순서 R03/R09, 같은 체형·능력치는 유지한다. 아직 색상 시안이나 썸네일은 제작하지 않았다.

## 벽·볼륨·카메라에 적용할 범위

벽은 큰 평면의 명암과 절제된 얼룩·볼트 자국으로 질감을 만든다. 작은 점과 균열을 화면 전체에 촘촘하게 넣어 홀드처럼 보이게 하지 않는다. 다면체 볼륨은 기존 벽 모듈의 시각 요소로 사용할 수 있지만, 붙잡을 수 있는지 여부는 09의 슬롯 데이터로만 결정한다.

현재 활성 등반 영역은 한 평면이다. 참고의 돌출·경사 벽을 보고 벽 뒤로 돌기, 옆면 잡기, 오버행의 깊이 이동을 추가하지 않는다. 비활성 측면/배경에 공간감을 표현하고, 활성 접점 주변의 시각적 돌출은 손발 앵커와 일치시킨다. 새로운 표면을 오르게 하려면 별도 게임 설계 변경이 필요하다.

MVP의 가로 화면·후면 고정 정사영·중앙 월드 창 3.4×3.8m·좌우 22% 패드를 유지한다. 원작과 같은 원근 카메라·인물 화면 점유율을 현재 설계의 필수 조건으로 만들지 않는다. 비교할 때 우리 조작 패드가 차지하는 공간과 동일한 월드 시야를 함께 기록한다.

게임 그림의 비교 대상은 SNS 화면을 뺀 가로 장면이다. 위쪽의 검은 여백이나 하단 설명·오른쪽 좋아요 버튼을 게임 HUD로 옮기지 않는다. 영상 자막의 위치도 HUD 배치 기준이 아니다.

## v0.4 변경·남은 결정

이번에는 U03의 참고를 REF01로 지정하고, 아트 방향·팔레트·캐릭터 의상·벽 표현·모바일 단순화 순서를 문서에 반영했다. 1캐릭터·3색·1테마·8홀드 메시·12스테이지의 범위와 조작·물리·저장 규칙은 늘리지 않았다. 17/21은 해당 버전 당시 검토 기록으로 보존한다.

이제 참고 이미지를 다시 요청할 필요는 없다. 남은 것은 우리 캐릭터 시안/모델을 제작한 뒤 비교하는 일, 선의 실제 두께와 텍스처 밀도 조정, 실행 품질과 성능 확인이다. 이는 현재 수행한 문서 분석과 구분하며 개발·기기 실행 검증은 계속 제외한다.

문서 검수에서는 내부 링크, REF01 식별 정보, 기존 콘텐츠 수량·물리 수치와의 충돌, 현재 문서에 남은 “참고 미수신” 표현을 확인한다. 게임 에셋·코드·프로토타입·빌드·기기 실행 결과는 이번 변경에 포함하지 않는다.

정적 검수 결과: Markdown 25개와 기존 SVG 1개, 내부 상대 링크 140개를 확인했고 깨진 링크는 없었다. REF01의 크기·바이트 수·SHA-256은 첨부 파일과 일치한다. ART01~ART06, 기존 리그 검토 포즈 20개·스테이지 12개, 비교 가중치 합계 100을 확인했다. 표 열 수·문서 펜스·SVG 구조도 검사했다. 이는 문서 검수이며 게임 플레이·렌더링 검증 결과가 아니다.

## v0.5 동작 설계와의 관계

본 문서의 REF01 관찰·팔레트·아트 방향은 유지한다. 동작 판정은 새 [04](04_pose_and_physics.md)가 우선하며, XY 입력을 유지하되 깊이·관절 방향·연속 경로도 판정에 포함한다. 기존 “2D 판정 유지” 설명을 Z와 뼈 twist가 아무 제약도 없다는 뜻으로 적용하지 않는다. CH01 1차 제작 이력은 23, 회전 현상의 정적 점검은 24에 있다.
