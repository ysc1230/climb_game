# 26. 실내 볼더링 기술 목록(확정)

2026-10-31(KST) · v0.6 · 판단·실행 규칙은 [27](27_technique_actions_design.md)

공개 용어집·교육 자료에서 기술을 조사한 뒤(출처는 아래), 사용자 결정에 따라 **클립(로프 장비)을 쓰거나 실내 볼더링에서 하지 않는 기술, 구현이 어렵거나 의미가 적은 기술을 뺐다.** 용어 정의는 출처 요약이며 이 게임의 수치를 보증하지 않는다.

## 포함 기술

| 단계 | 기술 | 내용 | 움직이는 부위 |
| --- | --- | --- | --- |
| 1 | 인사이드 엣지 | 엄지발가락 쪽 모서리로 정면 자세 디딤 | 발 |
| 1 | 아웃사이드 엣지(백스텝) | 새끼발가락 쪽 모서리로 딛고 같은 쪽 엉덩이를 벽으로 | 발 + 엉덩이 |
| 1 | 드롭니 | 디딘 발을 돌려 무릎을 안쪽 아래로, 엉덩이를 벽으로 | 발 회전·무릎 + 엉덩이 |
| 1 | 하이스텝 → 일어서기(록오버) | 발을 높이 올리고 그 발 위로 체중을 옮겨 일어섬 | 발 → 몸통 |
| 1 | 데드포인트 | 몸이 올라가는 정점에서 한 손으로 조금 먼 홀드를 잡음 | 몸통 + 손 |
| 1 | 플래그(같은 쪽) | 빈 발을 같은 쪽 바깥으로 뻗어 균형 | 발 |
| 1 | 인사이드 플래그 | 빈 발을 지지발 앞(벽 쪽)으로 교차 | 발 |
| 1 | 아웃사이드 플래그 | 빈 발을 지지발 뒤로 교차 | 발 |
| 1 | 록오프 | 한 팔을 굽혀 고정하고 다른 손을 뻗음 | 팔 + 몸통 |
| 1 | 휴식(팔 펴기) | 팔을 펴 뼈로 매달리고 발에 체중 | 몸통 |
| 1 | 크로스 | 팔을 교차해 반대쪽 홀드 | 손 |
| 1 | 매치 | 반대 손이 잡은 홀드를 같이 잡음 | 손 |
| 1 | 풋스왑 | 같은 발판에서 발 바꾸기 | 발 |
| 1 | 사이드풀 | 옆 방향 모서리를 몸 쪽으로 당김 | 손 |
| 1 | 개스턴 | 옆 방향 모서리를 바깥으로 밀듯이 당김 | 손 |
| 1 | 언더클링 | 아래를 향한 모서리를 위로 당김 | 손 |
| 2 | 힐훅 | 뒤꿈치를 걸어 당김 | 발 |
| 2 | 토훅 | 발등을 걸어 당김 | 발 |
| 2 | 스미어링 | 홀드 없는 벽면을 마찰로 디딤 | 발 |

## 뺀 기술과 이유

| 기술 | 이유 |
| --- | --- |
| 핸드·핑거·피스트·풋 재밍, 암바, 치킨 윙, 체스트 재밍, 오프위드스, 레비테이션, 스프래그 | 크랙 지형. 실내 볼더링 홀드 벽에서 하지 않음 |
| 침니, 펜듈럼, 행독, 뱃 행 | 로프·특수 지형 |
| 다이노, 캠퍼싱, 패들링, 포고, 랴슈 | 두 손이 모두 떨어지는 비행. 데드포인트로 대체 |
| 바이시클, 피겨 4·9, 알파인 니 | 특수 지형, 조건이 복잡하고 쓰임이 적음 |
| 레이백, 스테밍(브리징) | 모서리·마주 보는 벽 필요. 등반 평면이 하나 |
| 니바, 맨틀 | 큰 볼륨·탑아웃 지형 필요. 완등은 정상 홀드 양손 유지 |
| 크림프·슬로퍼·핀치·포켓 구분 | 홀드 모양별 손힘 모델이 없음. 잡은 위치 품질(27 §8.1)로 대신함 |
| 로즈 무브 | 몸통 회전 한계 밖 |
