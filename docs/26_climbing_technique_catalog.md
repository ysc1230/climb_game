# 26. 클라이밍 기술 목록과 게임 반영 상태

2026-10-31(KST) 조사 · 동작 설계의 기준은 [25](25_movement_constraints_and_moves.md)와 [04](04_pose_and_physics.md)

공개 용어집·교육 자료에서 클라이밍 기술을 모아 분류했다. 상태는 현재 구현(tuning_version 3) 기준이다.

- 구현: 게임 판정에서 동작함
- 부분: 근사하거나 일부만 동작함
- 설계만: 25에 있으나 미구현
- 제외: 25의 제외 목록, 또는 현재 판정 모델(벽면 준정적·로프 없음·실내 단일 평면) 밖

용어 정의는 아래 출처의 요약이다. 이 게임의 수치나 판정을 보증하지 않는다.

## 손 잡기(홀드 사용법)

| 기술 | 내용 | 게임 상태 |
| --- | --- | --- |
| 저그(jug) | 크고 잡기 쉬운 홀드 | 부분: 일반 손 슬롯. 크기별 차이 없음 |
| 크림프(오픈/하프/풀) | 작은 모서리를 손끝으로 | 제외: 홀드 모양별 힘 차이 없음 |
| 슬로퍼 | 모서리 없는 둥근 홀드, 접촉 면적과 마찰 | 제외: 마찰 판정 없음 |
| 핀치 | 엄지와 손가락으로 집기 | 제외 |
| 포켓·모노 | 구멍에 손가락 1~3개 | 제외 |
| 사이드풀 | 옆으로 당기기 | 부분: 손 힘 원뿔 ±65° 안의 옆 힘 |
| 개스턴 | 몸 쪽에서 바깥으로 밀기 | 제외: 손 힘 방향 고정(위쪽 축) |
| 언더클링 | 아래쪽 홀드를 손바닥 위로 당기기 | 제외: 어깨 0.10m 아래 손은 하중 없음 |
| 팜(palming)·맨틀 | 손바닥으로 눌러 올라서기 | 제외: 누르는 손 접촉 유형 필요(25) |
| 매치·섀도 매치 | 한 홀드에 두 손 / 빠르게 손 바꾸기 | 구현: HandMatch(슬롯 2개 홀드만) |
| 크로스 / 드라이브바이 | 팔을 교차해 먼 홀드 | 부분: CrossReach 정적만, 동적 미지원 |
| 로즈 무브 | 팔을 크게 교차해 몸이 돌아감 | 제외: 몸통 회전 한계 |

## 발 사용(풋워크)

| 기술 | 내용 | 게임 상태 |
| --- | --- | --- |
| 엣징(인사이드/아웃사이드) | 신발 모서리로 작은 발판 딛기 | 부분: 발 슬롯 지지. 엣지 종류 구분 없음 |
| 토(발끝) 딛기 | 발끝으로 정밀하게 | 부분: 표현만 |
| 스미어링 | 홀드 없이 벽면 마찰로 딛기 | 제외: 홀드 밖 접촉 없음(25) |
| 하이스텝 | 발을 높이 올리기 | 구현: HighStep |
| 록오버·스탠드업 | 높은 발 위로 체중을 옮겨 일어서기 | 구현: StandUp(골반을 올린 발 위로) |
| 플래깅(일반/인사이드/아웃사이드) | 빈 발을 뻗어 균형 | 부분: Flag. 벽면 내 효과만, 교차 플래그 구분 없음 |
| 백스텝 | 새끼발가락 쪽 모서리로 딛고 엉덩이를 벽에 | 설계만: SideOn(yaw 미구현) |
| 드롭니(이집션) | 무릎을 안쪽 아래로 돌려 엉덩이를 벽에 | 설계만: MV07, yaw·발 회전 필요 |
| 풋스왑 | 같은 발판에서 발 바꾸기 | 부분: FootSwap 라벨. 한 발 해제 후 교체 |
| 힐훅 | 뒤꿈치를 걸어 당기기 | 제외: 당기는 발 접촉 유형 필요(25) |
| 토훅 | 발등을 걸어 당기기 | 제외: 같은 이유 |
| 힐-토 락·바이시클 | 두 발로 한 홀드를 맞물기 | 제외 |
| 니바 | 무릎을 끼워 쉬기 | 제외 |
| 알파인 니 | 발 대신 무릎을 홀드에 | 제외 |

## 몸의 위치·균형

| 기술 | 내용 | 게임 상태 |
| --- | --- | --- |
| 직선 팔(스트레이트 암) | 뼈로 매달려 근육 아끼기 | 구현: Rest 팔 선호 0.70m, 손 하중 피로 |
| 삼지점(트라이포드) | 세 접점 유지 후 한 팔다리 이동 | 구현: 접점 개수 강제 없이 힘 균형으로 판단 |
| 레스트·노핸드 레스트 | 체중을 발로 옮겨 쉬기 | 부분: Rest 회복(발 2개·저하중). 노핸드는 플랫폼만 |
| 록오프 | 한 팔을 굽혀 고정하고 다른 손 뻗기 | 구현: LockOff(팔 0.42m) |
| 힙 턴·트위스트 락 | 엉덩이를 벽에 붙여 옆으로 | 설계만: yaw 미구현 |
| 체중 이동(웨이트 시프트) | 다음 동작 전 무게중심 옮기기 | 구현: 의도 목표 Shift, 거부 사유 "먼저 체중을 옮겨야 해요" |
| 트래버스 | 옆으로 이동 | 구현: Traverse |
| 다운클라임 | 내려오기 | 구현: DownClimb 라벨 |
| 반도어(barn door) | 한 축 접점에서 몸이 문처럼 열림 | 부분: 벽면 밖 회전 미모델, 대신 각도·관절 제한 |
| 레이백 | 손으로 당기고 발로 밀어 옆 대항력 | 제외: 수직 크랙·옆 힘 대형 접촉 필요 |
| 스테밍(브리징)·침니 | 마주한 두 면을 밀기 | 제외: 단일 등반 평면 |
| 컷루즈·데드 행 | 발이 빠져 손으로만 매달림 | 부분: 발 0개 매달림 허용, 진자 운동 없음 |
| 피겨 4·피겨 9 | 다리를 팔에 걸어 높이 얻기 | 제외 |
| 뱃 행 | 발을 걸어 거꾸로 매달림 | 제외 |

| 기술 | 내용 | 게임 상태 |
| --- | --- | --- |

| 다이노·래치 | 도약해 먼 홀드 잡기 | 제외(25) |

## 크랙·재밍

핸드 재밍, 핑거 재밍(핑거 락), 피스트 재밍, 풋 재밍, 암바, 치킨 윙, 체스트 재밍, 오프위드스, 레비테이션, 스프래그가 있다. 모두 **제외**다. 실내 홀드 벽·단일 평면에는 크랙 지형과 끼우기 접촉이 없다.

## 게임에 넣을 때의 우선순위 제안

25의 구현 순서와 현재 판정 모델로 보면 아래 순서가 현실적이다.

1. **SideOn·드롭니·백스텝·힙 턴:** 25의 MV07에 이미 설계가 있다. 골반 yaw(±40°)와 발 pivot 허용 슬롯만 구현하면 실내 볼더링에서 가장 자주 쓰는 동작군이 열린다.
2. **사이드풀·개스턴·언더클링:** 슬롯마다 힘 축 방향(force_axis)을 지정하면 된다. 04 §4의 지지 계산이 이미 축을 받는다. 데이터만 늘리면 되므로 비용 대비 효과가 크다.
3. **힐훅·토훅:** 당기는 발 접촉 유형과 해제 시 하중 이전이 필요하다(25 제외 → 후속).
4. **데드포인트:** 준정적 모델을 벗어나는 짧은 탄도 구간과 잡기 창이 필요하다. 다이노보다 범위가 작다.
5. **스미어링·맨틀:** 홀드 밖 마찰 접촉, 누르는 손 접촉이 필요하다.
