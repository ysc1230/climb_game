# 32. 홀드 디자인(v2)

2026-11-05(KST) · 사용자 요청: "홀드 디자인이 너무 별로야" → design 스킬로 기획하고 Blender로 제작

## 1. 이전 홀드의 문제

- 녹슨 갈색(#985448) 홀드가 주황 흙빛 벽(#A66A4A)과 같은 계열이라 묻혔다.
- 납작한 콩알 모양이라 어디를 잡는지, 손홀드인지 발판인지 모양으로 알 수 없었다.
- 화면 크기(지름 약 0.15m)가 실제 잡기 영역(폭 최대 0.36m)과 달랐다(v7에서 크기는 영역에 맞춤).

## 2. 방향

실내 볼더링장 합판 벽에 박힌 레진 홀드를 Cairn 풍 로우폴리 툰으로 그린다(22 아트 방향). **모양과 색이 곧 정보다.**

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| hand_body | #2B7A6F 옥빛 청록 | 손홀드 몸체. 벽(주황·모래)의 반대색 |
| hand_lip | #8FD0BC | 손가락이 걸리는 윗날 띠 |
| foot_body | #5E4C70 보라 회색 | 발판 몸체(손홀드와 색·모양 모두 다르게) |
| foot_lip | #C4B0D6 | 발판 디딤 윗면 |
| goal | #D9B872 / #F1D59A | 정상 홀드(기존 target_cream 계열) |
| bolt | #302820 잉크 | 볼트 구멍, 외곽선 |
| 흰색 | – | "지금 놓으면 잡힘" 빛 전용. 홀드 색으로 쓰지 않는다 |

- 패드 색(하늘색·보라)과 겹치지 않게 채도를 낮췄다.
- **강조는 하나만:** 손이 걸리는 윗날을 밝은 띠로 칠해 "여기를 잡는다"를 보여 준다. 정면 카메라에서도 보이도록 윗면과 앞면 위쪽에 칠한다.
- **모양:**
  - 손홀드: 위쪽에 안으로 파인 립이 있는 렌즈형 선반(저그·에지·둥근 저그 3종). 립의 방향·길이가 잡기 영역 선분과 같다.
  - 발판: 작고 둥근 조약돌형 칩 3종.
  - 정상 홀드: 크고 깊은 크림색 저그 1종.
- 면은 매끈하게 하지 않고 로우폴리 면을 남긴다. 툰 셰이더 밴드와 잉크 외곽선(폭 0.012)을 쓴다.

## 3. 제작

- 생성기: `tools/holds/make_holds.py`(Blender 배경 실행 `blender -b --python tools/holds/make_holds.py`). 단면 프로필을 길이 방향으로 밀어 만들고, 양 끝을 오므리고 가운데를 흔들어 손으로 깎은 느낌을 낸다.
- 출력: `game/art/holds/holds.glb`(hand_0..2, foot_0..2, goal). 단위 메시는 X 길이 ±0.5, Y 높이 ±0.5, Z 깊이 0..1이다. 재질 슬롯은 몸체·윗날·볼트 구멍이다.
- 게임(`play_3d.gd`)은 슬롯마다 메시를 늘린다.
  - 손홀드: 길이 = 2·반폭 + 0.04, 높이 0.17, 깊이 0.10(정상 0.13)
  - 발판: 길이 0.18, 높이 2·반높이 + 0.08, 깊이 0.08
  - 변형은 슬롯 키 해시로 고른다.
  - 같은 메시를 겹친 빛 메시가 잡을 수 있으면 흰색, 튜토리얼 목표면 노란색으로 깜빡인다.

## 4. 남은 것

- 기기 화면에서 크기·대비 확인(미검증)
- 홀드 종류(저그·에지·슬로퍼·핀치)가 판정과 연결되면, 모양 변형을 grip_modes에 맞춰 고른다(지금은 무작위 3종)
- 볼륨(큰 다면체)·발판 전용 칩 추가

## 5. v2(2026-11-05, 사용자: "홀드가 너무 크고, 모양이 동그랗기만 해서 별로, 다양한 디자인 필요")

- **크기:** 대부분 작은 홀드로 바꿨다.
  - 손홀드는 다섯 개 중 넷이 작은 종류이고, 하나 정도가 중간이다.
  - 넓은 잡기 영역(반폭 ≥ 0.15)과 정상만 큰 홀드다.
  - 메시는 실제 크기(작은 홀드 약 8cm)로 만든다. 화면에서 읽히도록 배율을 준다: 작음 1.9, 중간 1.5, 큼 1.25, 발판 1.9.
  - 잡기 판정(영역·여유)은 그대로다. 잡을 수 있으면 홀드 자체가 빛나 위치를 알려 준다.
- **종류(17개 메시):**

| 크기 | 메시 | 모양 |
| --- | --- | --- |
| 작은 손홀드 | hs_crimp_0/1 | 얇고 날카로운 날(크림프) |
| | hs_edge_0/1 | 약간 파인 에지 |
| | hs_pinch_0 | 세로 갈비(양쪽에서 집기) |
| | hs_pocket_0 | 구멍이 파인 돌기(포켓) |
| | hs_nub_0/1 | 각진 돌기(너브) |
| 중간 | hm_jug_0 | C자 단면 저그 |
| | hm_sloper_0 | 윗면이 눌린 둥근 슬로퍼 |
| 큼 | hl_jug_0 | 큰 저그 |
| | hl_sloper_0 | 큰 슬로퍼 |
| 발판 | f_chip_0/1/2 | 각진 칩 |
| | f_edge_0 | 얇은 발 에지 |
| 정상 | goal | 크림색 큰 저그 |

- 고르는 규칙은 `play_3d.gd hold_variant`(슬롯 키 해시로 고정)다. 잡는 방향으로 돌리고 ±8° 흔든다.
