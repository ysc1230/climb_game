# 39. 더미 기준 몸 치수 정립

v0.1 (2026-11-13) — 사용자 지시: "무조건 이 더미 기준으로 모든 수치를 다시 재계산하고 정립해." 파츠와 얼굴은 나중에 하고, 먼저 더미로 시험한다.

- 기준 파일: `main`의 `temp/reference_climber.glb`(뼈 17개 + 뼈마다 타원 덩어리, 사용자 제작), `temp/climber_character_final_brief.md`(키 170cm, 양팔 195cm).
- 이 문서는 **정립한 값**이다. 코드에는 아직 넣지 않았다(다음 단계).

덩어리 반지름(팔다리 굵기): 위팔 0.035, 아래팔 0.030, 허벅지 0.065(좌우)/0.053(앞뒤), 정강이 0.047/0.039. 몸통 반폭: 가슴 0.16, 척추 0.135, 골반 0.14. 앞뒤 반: 0.13/0.11/0.115. 머리 반지름: 좌우 0.095, 앞뒤 0.078, 위아래 0.125.

파일에서 고칠 것(더미를 게임에 넣을 때 처리):
- 뼈와 상관없는 반지름 1m 구(`Icosphere`)가 들어 있다 → 지운다.
- 손 뼈 길이 0.29, 발 뼈 0.40이 덩어리(0.16, 0.19)와 다르다 → 덩어리 기준으로 다시 놓는다.
- 게임의 손 뼈(hand) 시작점은 **손 접점 = 손가락 뿌리**다. 더미 손 0.16을 손바닥 0.09 + 손가락 0.07로 나눠, 손가락 뿌리를 손목에서 0.09에 둔다. 손가락 뼈(finger)는 그 뒤 0.035.

### 닿는 범위 비교(골반 깊이 0.28, 어깨–벽 깊이 0.21 기준 벽면 최대 거리)

| | B안 | 더미 |
|---|---|---|
| 어깨에서 손 접점 최대(3D) | 0.555 | 0.73 |
| 벽면 최대(평면) | 0.51 | 0.70 |
| 골반 위 손 최고 높이(팔 위로) | 0.67 + 0.51 = **1.18** | 0.49 + 0.70 = **1.19** |
| 골반에서 옆으로 손 최대 | 0.18 + 0.51 = 0.69 | 0.175 + 0.70 = **0.875** |
| 다리 최대 | 0.785 | 0.81 |

→ **위로 닿는 높이는 거의 같다**(어깨가 18cm 낮아진 만큼 팔이 길다). 옆·아래로는 손이 약 19cm 더 닿고 다리는 2.5cm 더 닿는다. 문제 배치는 대부분 그대로 풀리고, 옆 홀드 문제는 쉬워질 수 있다 → 적용 뒤 모든 문제 재검증(의도 경로 자동 재생)으로 확인한다.

## 4. 적용 순서(다음 단계)

1. 더미를 게임 모델로 만든다(`art_source/character/dummy/`): 구 삭제, 손·발 뼈 다시 놓기, 손가락 뼈, 덩어리 단색 재질. 남녀 대신 더미 1종.
2. Tuning·표현 상수를 위 표대로 바꾸고 docs/04 조정표를 같이 고친다.
3. 전체 시험(문제 배치 재검증 포함). 닿지 않거나 너무 쉬워진 문제는 목록으로 보고하고 사용자와 정한다.
4. 맥 게임 화면(뒤 시점)에서 제작안 §"게임 화면에서의 채택 기준" 자세(팔 뻗기, 하이스텝, 옆 뻗기, 한 발 떼고 먼 홀드)를 찍어 확인 → APK.
