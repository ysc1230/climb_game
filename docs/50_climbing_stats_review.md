# 50. 등반에 영향을 주는 능력치 전체 검토

v0.1 (2026-11-19). 사용자: "캐릭터의 등반에 있어 영향이 있는 능력치들이 어떤 게 있는지 전부 검토해. 기존 조정됐었던 수치들도 있으면 수치도 트래킹해서 알려 줘."

출처: `game/scripts/climbing/tuning.gd`(판정 수치, `TUNING_VERSION` 10), `fatigue.gd`, `support_solver.gd`, `climb_rules.gd`, `grip_check.gd`, `hold_area.gd`, `technique_judge.gd`, `content/grade_rules.gd`와 각 파일의 git 기록. 날짜는 커밋 날짜.

## 0. 먼저 알아 둘 것

- **판정 몸은 하나다.** 남성·여성·더미를 골라도 등반 능력치는 같다(2026-11-13 더미 몸으로 통일, docs/39). 캐릭터 선택은 겉모습만 바꾼다. 모델 키(남·여 약 1.82m)는 화면용이고 판정과 상관없다.
- **"능력치"는 세 부류다.** ① 몸(길이·관절 범위) ② 힘(지지·손 힘·피로) ③ 규칙(떨어지기까지 시간, 잡기 여유, 기술 조건). 지금은 모두 상수이고 캐릭터마다 다르게 둘 수 있는 구조는 없다.
- **판정 수치 판(`TUNING_VERSION`)**: 4(10-31 잡기 품질) → 5(11-04 문 열림 부담) → 6(11-04 잡기 여유) → 7(11-07 몸통 끌기) → 8(11-11 B안 몸) → 9(11-11 Tripo 팔 실측) → **10(11-13 더미 몸, 지금)**. 10 이후 바뀐 값(발 몫·다이노 등)은 판 번호를 올리지 않았다.

## 10. 검토 의견

1. **캐릭터마다 능력치가 없다.** 게임 요소로 쓰려면(예: 팔이 긴 캐릭터, 손 힘이 센 캐릭터) 위 수치 중 몇 개를 몸마다 두어야 한다. 후보: 팔·다리 길이, 손 힘 최대·회복, 손 최대 하중. 지금은 문제 설계(등급·관문)가 "한 몸" 기준이라 넣으면 등급이 몸마다 달라진다.
2. **문서와 다른 값이 있다.** docs/04의 피로표(발 개수 계단)는 11-19 발 몫 규칙으로 바뀌었다. docs/04에 바뀐 점을 적어야 한다.
3. **`TUNING_VERSION`을 올리지 않은 변경**이 있다(작은 홀드 배율 11-14, 발 몫 11-19, 다이노). 기록·저장 기록 비교에 판 번호를 쓰므로 11을 올리는 것을 권한다.
4. **미검증 수치**: 드롭니·백스텝(35°/30°)의 실제 이득, 문 열림 용량(지금 몸에서 문 열림이 거의 안 생김, docs/47).
