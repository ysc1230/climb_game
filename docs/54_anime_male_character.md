# 54. 애니 남성 캐릭터 (Tripo, 2026-11-22)

사용자: "캐릭터를 tripo를 통해 잘 만들고 싶은데 너무 별로야.
1. 내가 원하는 이미지처럼 안 나와. 20년 전 이미지 캐릭터 같아.
2. 옷을 입히면 기존 캐릭터가 입고 있는 옷 위에 입혀지게 돼.
3. claude에서 tripo를 통해 만들 수 있어?"

이어서 기본 그림 3장(정면·옆·뒤, T자, 애니 그림체, 흰 티·보라 하네스·남색 바지·노란 암벽화)을 주고 "ㄱㄱㄱ".

## 1. 원인 판단(설계자)

1. **옛날 캐릭터 같은 이유**
   - 예전 승인 시안(`female/references/approved_concept.png`)이 매끈한 플라스틱 3D 만화 렌더였다.
   - 게임에 넣을 때 몸을 1만 2천 삼각형, 텍스처 1024로 줄여 얼굴이 뭉개졌다.
   - Tripo의 사실적 재질(PBR)을 만화 셰이더에 그대로 썼다.
2. **옷이 겹쳐 입혀지는 이유**
   - 몸은 옷을 입은 채 한 덩어리로 생성됐다.
   - 새 옷은 따로 생성한 뒤 크기만 맞춰 1.2cm 띄워 겹쳤다(docs/46).
   - 권장: 옷 세트마다 같은 얼굴·비율로 캐릭터를 통째로 생성해 같은 뼈대를 씌운다. 색만 다르면 텍스처만 바꾼다.

## 2. 만든 것

- **입력**
  - `art_source/character/anime_male/references/` front·left·back(사용자 그림).
  - 옆 그림은 캐릭터가 화면 왼쪽을 보는 모습이라 남성 v2와 같이 left 자리에 넣었다. 오른쪽은 비웠다(Tripo는 정면 + 2장 이상).
- **Tripo 생성**
  - `tools/tripo_multiview.py`로 국제판 API(api.tripo3d.ai v2)를 썼다. 이 계정 키는 v3(openapi.tripo3d.com)에서 "Invalid API key"였다.
  - multiview_to_model, v3.1-20260211, 텍스처 standard, **pbr 끔**(그림 색만). 30크레딧(390 → 360), 93초.
  - 작업 기록은 `tripo_v1/task.json`, 원본은 `tripo_v1/model.glb`(삼각형 약 144만).
  - 파이썬 기본 요청 헤더는 Cloudflare가 막아(1010) User-Agent를 붙였다.
- **게임용**
  - `TRIPO_CHAR=anime_male blender -b --python art_source/character/build_tripo_rig.py` → `game/art/characters/climber_anime_male.glb`(1.2MB).
  - 기준점(정규화 높이): 어깨 0.75, 발목 0.075, 무릎 0.25, 손끝 0.50, 가랑이 0.40, 손목 0.394, 손가락 뿌리 0.453.
    - 가랑이는 다리 사이 틈이 시작하는 높이다. 무릎이 붙어 있어 가운데 최저점으로 재면 무릎이 나온다.
  - 결과: ×1.926(키 1.93m).
  - 삼각형 24,000(이전 12,000), 텍스처 2048(이전 1024).
  - `skin_clean`: 옆모습 그림의 앞으로 뻗은 주먹이 오른 아래팔에 회색 얼룩으로 찍혀, 팔 UV 안에서 피부보다 많이 어두운 화소 1,198개를 피부색으로 덮었다.
- **게임 연결**
  - `data/characters.json`의 남성(body id `male`, 저장값 그대로)과 기본 모델을 이 모델로 바꿨다.
  - 매끈한 남성(climber_smooth.glb)은 파일만 남겼다.
- **테스트 삼각형 예산**: 12,500 → 25,000(`test_character_assembler.gd`). 화면에 캐릭터가 하나이고, 아트 의뢰 기준(docs/14 CH01 15k~25k) 안이다.
- **캐릭터 고르기 미리보기 조명**: 흰 옷·피부가 하얗게 날아가 주변광 0.55 → 0.3, 해 0.8로 낮췄다.

## 3. 비용(2026-11-22 공식 가격표)

| 항목 | 크레딧·금액 |
|---|---|
| Tripo multiview → 3D | 텍스처 없음 20 / standard 30 / detailed 40 / 8K 50크레딧, 형태 정밀 +20, 자동 리깅 25(안 씀, 직접 붙임) |
| Tripo 크레딧 값 | 개발자 페이지 1크레딧 = ¥0.07(중국 결제 기준, 국제판 가격은 확인 못 함) |
| OpenAI 이미지 | gpt-image-1은 2026-10-23 종료. 후속 gpt-image-2.5-sunburst는 토큰 요금(이미지 출력 $30/100만)이라 장당 값은 만든 뒤 `tools/openai_image.py`가 실제 토큰으로 계산해 보여 준다. 이번에는 사용자 그림이 있어 쓰지 않았다. API 크레딧이 0이라 충전이 필요하다 |

키는 저장소에 두지 않는다. 각 도구는 환경 변수 `TRIPO_API_KEY`·`OPENAI_API_KEY`에서만 읽는다.

## 4. 확인한 것·못 한 것

- **확인한 것**
  - Blender 평면 렌더(정면·얼굴·옆·뒤): 그림과 거의 같다.
  - 게임 캡처(뒤·비스듬히, 오르는 자세)와 캐릭터 고르기 화면.
  - 전체 테스트 443개.
- **못 한 것**
  - 폰 화면 확인.
  - 큰 자세에서 하네스·초크백 변형은 자세히 보지 않았다.
  - 게임 카메라가 뒤에 있어 얼굴은 고르기 화면에서만 보인다.
  - 피부가 만화 셰이더·조명에서 노르스름하게 보인다(여성도 같음).
- **다음(제안)**
  - 옷 세트는 같은 그림체로 옷만 바꾼 그림 3장 → 캐릭터를 통째로 생성(세트당 30크레딧).
  - 고르기는 상의·하의 따로 대신 "옷 세트"로 한다.
