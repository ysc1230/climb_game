# 56. 남성 기본 착장(2026-11-23)

## 1. 사용자 요구

- 첨부 그림 2장과 함께: "헤어스타일과 신발은 첨부이미지 기준으로 만들어. 글자나 로고 다 빼고 밋밋하게 만들어. 상의는 흰티 하의는 청바지 초크백은 회색으로 밋밋하게. 이걸 남성 캐릭터의 기본 착장으로 해. 아무것도 안입는건 나중에 하나의 옵션으로 만들거야."
  - 머리 그림: 만화 남자. 짙은 갈색의 둥근 바가지 머리이고, 앞머리가 눈썹까지 내려오고 끝이 뾰족한 다발이다. 귀는 보인다.
  - 신발 사진: 벨크로 두 줄 암벽화. 윗면은 회색 스웨이드, 둘레·코·뒤꿈치는 검은 고무다.
  - 신발 사진은 상품 사진이고 머리 그림은 출처를 모른다. 그래서 두 그림 모두 저장소에 넣지 않았다.
- 크레딧을 쓰지 않았다(Tripo·OpenAI 생성 없음). 모두 Blender 코드로 만들었다(docs/55 §1 규칙).
- 방향은 docs/55 §2를 따른다. 속옷만 입은 맨몸(대머리 v2) 위에 옷을 따로 만들고, 덮인 피부는 숨긴다.

|---|---|---|---|
| `P_body_male` | 남성 몸 | 대머리 v2 몸에서 옷이 덮는 면을 지움 | 8,841 |
| `P_hair_bowl` | 바가지 머리 | 두피를 재어 띄운 둥근 껍질 | 4,176 |
| `P_top_white_tee` | 흰 티 | 몸 면 복사 → 천처럼 매끈 → 띄움 | 7,005 |
| `P_pants_jeans` | 청바지 | 몸 면 복사 → 천처럼 매끈 → 띄움 | 8,122 |

- 색은 텍스처 한 장(32px, 8px 칸 8개)에서 UV로 고른다. 그래서 몸 텍스처와 같은 조명을 받는다(docs/55 §6.4).
  - 흰 티 (0.94, 0.94, 0.92), 청바지 (0.30, 0.43, 0.62), 머리 (0.29, 0.20, 0.14)
  - 신발 윗면 (0.66, 0.66, 0.65), 신발 고무 (0.17, 0.17, 0.18)
  - 초크백 (0.56, 0.56, 0.57), 허리띠 (0.30, 0.30, 0.31)
- 글자·로고·무늬는 없다.

## 3. 만드는 법(`build_outfit`, 게임 좌표 m: 골반 관절 0, 위 +Z, 앞 +Y)

### 3.1 티·청바지: 몸 면 복사

- **자르기(`cut`)**: 몸 메시를 경계면에서 잘라 끝단이 깔끔하다. 나눈 정점은 UV·가중치가 섞여 들어간다.
  - 티: 아랫단 0.06, 소매 끝 |x| 0.34, 목둘레(앞 0.545·옆 0.583·뒤 0.585).
  - 청바지: 허리(앞 0.10·뒤 0.115), 밑단 −0.845.
- **가중치**: 몸 정점 가중치를 그대로 쓴다. 그래서 몸과 똑같이 움직인다. 겨드랑이 아래 천도 위팔을 따르지 않는다(docs/55 §6).
- **천처럼 매끈하게(`envelope`)**
  - 라플라스로 매끈하게 하되, 가장 가까운 몸 면 안으로는 못 들어가게 한다.
  - 볼록한 곳(가슴·엉덩이)은 몸에 붙고, 오목한 곳(복근·등 골·무릎 뒤)은 천처럼 메워진다.
  - 겨드랑이·가랑이는 덜 한다(물갈퀴처럼 메워지지 않게).
  - 처음 쓴 Taubin 매끈하게로는 근육 굴곡이 그대로 비쳤다.
- **띄우기**: 이웃과 평균 낸 법선 방향으로 띄운다. 가는 삼각형 법선 때문에 끝단에 가시가 생겼다.
  - 티: 0.9cm. 아랫단 +1.2cm, 소매 +1.0cm 퍼진다.
  - 청바지: 0.7cm. 무릎 아래로 +1.2cm 퍼지고, 허리(티 안)는 0.3cm 안쪽이다.
- **가장자리 접기(`rim`)**: 끝단을 몸 쪽으로 접어 넣는다. 천 두께처럼 보이고, 끝단 틈으로 뒤가 비치지 않는다.

### 3.2 암벽화

- 발마다 발목 높이(−0.835) 아래 몸 정점의 볼록 껍질을 만든다. 발가락·발바닥 아치를 덮는 신발 모양이 된다.
- 복셀 1.1cm로 고른 격자로 다시 만들고, 발목 높이에서 입구를 자른다.
- 가중치는 가장 가까운 몸 정점에서 가져온다. 0.3cm 띄운다.
- 색 경계를 잘라 깔끔하게 했다.
  - 고무: 바닥 + 둘레 1.8cm. 코와 뒤꿈치 쪽은 4.8cm까지 올라간다.
  - 벨크로 두 띠: 발 길이 40~51%, 56~67%.
  - 나머지는 회색이다.
- 뒤꿈치 고리는 청바지 밑단을 뚫고 나와 뺐다.

### 3.3 머리카락

- 머리 안 한 점(0, −0.04, 0.70)에서 광선 144방향 × 14줄로 두피를 재고 띄운 둥근 껍질이다. 끝은 두피 쪽으로 접었다.
- 두께: 정수리 3cm, 옆 2.7cm(버섯 모양), 앞머리 1.3cm.
- 끝선 높이: 앞머리 0.731(눈썹 위), 귀 위 0.710, 뒤 0.652(목덜미).
- 앞머리 끝은 뾰족한 다발이다. 깊이 1.6cm, 14°마다. 뒤는 0.8cm다.
- 가중치는 head 1이다.
- 측정값
  - 눈썹 0.70~0.724, 귀 0.651~0.709, 정수리 0.82.
  - 측정 렌더는 scratch에서 했고, 대머리 v2 몸 기준이다.

### 3.4 초크백

- 회색 원통이다. 반지름 4.6cm(앞뒤 0.8배), 높이 0.012~0.135, 둥근 바닥이고 입구 안은 어둡다.
- 등 가운데(y −0.192)에 단다.
- 허리띠: 티 표면에서 0.4cm 띄운 1.6cm 띠(높이 0.114~0.130). 가방과 띠는 작은 고리로 잇는다.
- 가중치: 가방은 pelvis 1, 띠는 몸통(골반↔척추) 가중치다.

### 3.5 덮인 피부 지우기(`trim_body`)

- 옷마다 그 옷 경계에서 3cm(암벽화 2cm)보다 안쪽인 몸 면을 지운다. 몸은 24,000 → 8,841 삼각형이 됐다.
- 큰 자세에서 피부가 옷을 뚫고 나오지 않게 하려는 것이다.
- 끝단 아래 몸은 남긴다. 발목·목둘레·소매 틈으로 속이 비어 보이지 않게 하려는 것이다.

## 4. 게임 연결

- **`data/characters.json`**
  - 남성 = `climber_male_base.glb` + `P_body_male`.
  - 기본값: hair_bowl·top_white_tee·pants_jeans·chalk_gray·shoes_velcro.
  - 슬롯은 헤어·상의·하의·초크백·암벽화 순서다. 헤어·초크백은 남성만 있다.
  - 상의·하의·암벽화의 "기본(없음)"은 대머리·더미만 쓴다. 남성은 슬롯마다 한 가지다.
- **예전 저장**: 남성 + "base"는 남성 기본 착장으로 바뀐다(`normalize`).
- **홈 → 캐릭터**: 안내 문구를 "남성은 기본 착장 한 벌이에요. 옷 갈아입기는 지금 여성 캐릭터만 돼요."로 바꿨다.
- **애니 남성**(`climber_anime_male.glb`): 파일만 남긴다.
- **테스트** `test_male_default_outfit`
  - 기본 착장 다섯 가지가 같은 뼈대에 스키닝돼 있다.
  - 삼각형: 옷 하나 ≤ 10,000, 전체 ≤ 40,000.
  - 가슴·배와 다리에 몸 정점이 없다. 맨몸(대머리)에는 있다.
  - 흰 티 겨드랑이 아래는 위팔 가중치 0이다.
  - 예전 데이터에서는 실패하는 것을 확인했다.

## 5. 확인한 것·못 한 것

- **확인한 것**
  - Blender 렌더: 정면·뒤·옆, 머리·발·허리 확대, 오르는 자세(팔 들기, 다리 높이 올려 무릎 굽힘).
  - 게임 캡처: 캐릭터 고르기, G_V0_02·G_V1_01 오르는 장면.
  - 전체 테스트 445개 중 실패 0. SCRIPT ERROR 1건은 원래 있던 test_pelvis_tilt 'chest'다.
- **못 한 것**: 폰 화면 확인.

## 6. 남은 것

- **옷 없음 선택지**(사용자가 나중에): 남성 몸은 덮인 피부를 지운 것이라 지금은 맨몸을 못 보인다.
  - 지운 피부를 부위별 조각으로 남겨 "없음"일 때 보이게 하면 된다.
  - 또는 대머리 몸과 합치면 된다.
- **하네스**: 이번 요청에 없어 만들지 않았다.
- **머리 모양**: 그림보다 머리숱이 덜 크다. 게임 머리 크기를 그대로 써서다. 띄우는 두께(`hem_off`·정수리 0.030)로 조절한다.
