# 58. 벽 꾸밈: 실내 암장·자연 암벽 (2026-11-25, 오버행 실험 0.21)

## 사용자 요구

- "벽이 너무 예쁘지 않아. 어떻게 해야 할까?"
- 설계자 제안: 1 실내 암장(추천) / 2 자연 암벽 / 3 합판 다듬기.
- 사용자: "너가 하자는 대로 해 보자. 자연 암벽으로도 문제 하나 만들어 줄 수 있니?" "v7 문제 하나."

## 바꾼 것

- **문제마다 벽 꾸밈**(`RouteDef.wall_style`, JSON `wall_style`)
  - "gym"(기본, 빠지면 이것), "rock"이다.
  - 표현만 바뀐다. 판정·벽 각도와는 상관없다.
- **실내 암장(기본, 모든 기존 문제)**
  - 남회색 판넬(#5f6975)에 같은 판넬 무늬(이음선·볼트 구멍)다. 볼트 구멍은 더 어둡다.
  - 볼륨은 회색·숯색·흐린 파랑이다.
  - 실내 상자·배경·안개도 차분한 회색이다.
  - 예전 주황 합판 위에서는 청록 홀드가 묻혔는데, 회색 위에서는 색 홀드가 또렷하다.
- **자연 암벽**(`toon.gdshader rock_pattern`)
  - 벽면 좌표로 은은한 큰 색 변화, 비스듬한 결, 화강암 알갱이, 일부 자리에만 가는 금을 그린다.
  - 법선을 약하게 흔든다(`rock_bump` 1.5, 옆벽은 0: 비스듬한 빛에서 줄무늬가 생김).
  - 볼륨·볼트는 없다.
  - 홀드는 바위색 몸에 초크 묻은 흰 윗날이다(정상은 금색 그대로).
  - 바깥은 하늘색 상자와 흙 땅이다.
- **캐릭터 색**: 주변광·해는 그대로 두었다(빛을 바꾸면 캐릭터 색이 바뀐다는 사용자 의견). 바꾼 것은 벽·배경·안개뿐이다.
- **새 문제** G_V7_03 화강암 사선(rock)
  - G_V7_01 비틀린 사선과 같은 배치·정답 순서다. 벽 각도는 등급 그대로 40°다.
  - 검사기 통과, 점수 기준값·AI 고스트 기록을 만들었다.

## 확인

- 맥 캡처: V7-1(실내 암장), V7-3(자연 암벽).
- 처음 바위 무늬는 얼룩·금이 너무 많아 위장 무늬 같았다. 큰 변화를 줄이고 알갱이를 넣고 금을 드문드문으로 다듬었다.
- 전체 테스트 458개 실패 0.
- 폰에서는 확인하지 않았다.

## 남은 것

- 자연 암벽은 아직 평평한 면에 무늬다. 실제 바위처럼 면이 튀어나오거나 들어간 모양은 없다.
- V7-3은 V7-1과 배치가 같다. 바위다운 배치(바위 모양에 맞춘 홀드)는 따로 설계해야 한다.
