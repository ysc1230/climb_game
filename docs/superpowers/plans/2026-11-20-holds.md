# 작업 4 홀드 종류·방향·크기, 홀드·벽 새 그림 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홀드에 종류(8)·크기(S/M/L)·방향(5° 단위)을 주고, 이것이 지지 계산의 힘 방향·피로·발 몫·슬로퍼 몸 창으로 판정에 들어가게 하며, 종류가 모양으로 보이는 새 홀드·벽·매트 그림과 종류 이름표·홀드 사전을 더한다.

**Architecture:** 종류 수치는 데이터(`game/data/hold_types.json`)이고 `HoldTypes`(노드 없음)가 읽는다. `RouteDef._read_slot`이 새 필드(`hold_type`, `size`, `rot_deg`)에서 기존 `hand_area`·`foot_area`·`grip_modes`를 만들어 내므로 판정 코드는 대부분 그대로다. 종류에서 오는 새 효과(피로 배율, 발 몫, 슬로퍼 몸 창)는 `ContactInfo`에 실려 `ClimbRules`가 쓴다. 그림은 Blender 생성기가 종류별 메시를 만들고 `play_3d.gd`가 종류·rot대로 놓는다.

**Tech Stack:** Godot 4.7.2 GDScript, Blender 배경 실행(`tools/holds/make_holds.py`), 헤드리스 테스트 `game/tests/run_tests.gd`.

**Spec:** docs/superpowers/specs/2026-11-19-4-holds-design.md

## Global Constraints

- 색은 용도로만 구분(손 `#2B7A6F`/`#8FD0BC`, 합손 `#2F5FC4`/`#9CC0F4`, 발 `#5E4C70`/`#C4B0D6`, 탑 `#D9B872`/`#F1D59A`). 흰색은 "지금 놓으면 잡힘" 빛 전용.
- 방향 효과는 힘 방향(axis)·손 선분(dir)을 돌려서만 생긴다. "옆이면 ○○" 같은 손 규칙 금지.
- 옛 형식(새 필드 없음)은 지금처럼 읽힌다. 둘 다 있으면 새 필드가 이긴다.
- 조정값은 docs/04와 일치, `TUNING_VERSION` 10 → 11, 문제 `content_version` +1.
- 풋스왑·합발 규칙은 바꾸지 않는다.

## Review Focus

1. 옛 형식 루트(TX_GRIP, TX_TECH)가 그대로 읽히고 그립 방식 시험이 그대로 통과한다.
2. rot 275 같은 경계값에서 mode 이름이 가까운 쪽(270 → sidepull)으로 정해진다.
3. 포켓은 JSON에 `matchable: true`가 있어도 합손이 안 된다.
4. 슬로퍼 몸 창은 품질에만 곱해지고(피로·최대 하중 경로), 다른 종류에는 영향이 없다.
5. 옮긴 6문제·수업 10개가 모두 봇으로 완등된다(route_check 16 통과).

### Task 2: 판정 효과
- `ContactInfo`에 `fatigue_mult`, `foot_share`, `window`(슬로퍼 [hold_x, in, out, min]) 추가, `from_slot` 채우기. GripCheck·TechniqueJudge·ClimbSnapshot 복사.
- `ClimbRules`: 손 피로 × fatigue_mult, 발 몫 × foot_share, 품질 × 슬로퍼 창(골반 x 기준). `balance_view` 발 몫도 같은 배율.
- Test: 같은 자세에서 크림프가 저그보다 빨리 지침, 작은 발판 발 몫 0.85배, 슬로퍼 몸 창 1 → 0.4 선형, 사이드풀(rot 90)은 무게중심이 반대쪽일 때만 FEASIBLE, 언더클링(rot 180)은 높은 발이 있어야.

### Task 3: 기존 문제 옮기기
- `tools/holds/migrate_holds.py`: 손 matchable 또는 반폭 ≥ 0.08 → jug, < 0.05 → crimp, 사이 → jug S, 발 → foot_chip(가장 가까운 크기), 탑 → goal. content_version +1. 옮긴 필드는 지운다(matchable만 남김).
- 봇 다시 재기(route_check), score_ref 다시 쓰기, 결과 표를 스펙에 기록. 못 깨면 배치 조정.

### Task 4: 홀드 메시
