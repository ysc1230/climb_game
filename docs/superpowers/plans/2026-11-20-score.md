# 작업 3 점수·기록·도움 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 완등 시도에 100점 점수를 매기고, 플래시·무추락·최고 기록·고스트를 저장하고, 막혔을 때 힌트·시범 보기를 열고, 등급 이름·설명과 수업 뒤 안내를 더한다.

**Architecture:** 판정은 바꾸지 않는다. 노드 없는 `ScoreRecorder`가 판정 틱마다 세션을 읽어 시도 기록을 모으고(플레이 화면과 검사 봇이 같이 씀), `ScoreCalc`가 점수를 낸다. 기록은 `Progress.cleared`(완등만) + 새 `Progress.stats`(시도한 모든 문제)에 저장한다. 고스트는 `GhostTrack`(초당 10번 자세)으로 기록·보간하고 플레이 화면이 막대 사람으로 그린다.

**Tech Stack:** Godot 4.7.2 GDScript, 헤드리스 테스트 `game/tests/run_tests.gd`.

**Spec:** docs/superpowers/specs/2026-11-19-3-score-design.md

## Global Constraints

- 판정 수치·규칙 변경 없음(AGENTS.md). 점수는 판정이 이미 계산한 값만 읽는다.
- 점수 다섯 항목: 힘 아끼기 30 · 안정 25 · 정확한 손발 20 · 기술 15 · 마무리 10. 관문 없는 문제는 네 항목 ×100/85.
- 도움(자동 도움·힌트)을 쓴 시도는 "도움" 표시, 최고 점수·플래시·최고 시간·고스트에 넣지 않음. 완등·해금에는 셈.
- 무추락 = 문제를 연 뒤로 한 번도 떨어지지 않고 완등. 플래시 = 그 문제 첫 시도에 도움 없이 완등.
- 저장 형식 판 1 → 2. 이전 저장을 읽는다. docs/09를 같이 고친다.
- 화면은 휴대폰 가로 기준.

## Review Focus

1. 이전 판(SCHEMA 1) 저장을 읽으면 완등·해금이 그대로이고 stats는 빈 값이다.
2. `content_version`이 바뀐 문제: 완등·해금은 남고 최고 기록은 이전 판으로, 고스트는 지워짐.
3. 오래 쉬기만 해도 힘 아끼기 점수가 오르지 않는다(쓴 힘만 셈).
4. 관문 밖에서 기술을 써도 기술 점수가 오르지 않고, 같은 관문은 한 번만.
5. 기록 지우기 뒤 해금이 다시 계산되고 힌트·시범 보기 버튼이 다시 숨는다.
