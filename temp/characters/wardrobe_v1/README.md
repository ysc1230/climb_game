## 완료 및 사용 범위

루트의 GLB 6개는 Tripo 생성 원본, fitted_wip/는 여성 캐릭터의 좌표·크기에 맞추고 기존 리그의 가까운 정점 웨이트를 전사한 착용 검토본이다. 손질된 최종 의상이나 게임에 자동 연결된 결과가 아니다. 원본은 로컬 tripo-out/에도 보존하며 GitHub 전달에는 루트 GLB를 사용한다.

착용 검토본은 6개 모두 GLB 형식 오류 0건. 부모 스킨 경고가 남으며 기기·Godot 검증 전이다. review/에 단순 회전 비교 이미지와 상세 보고서를 보존했다. 생성 메시의 실제 삼각형 수는 목표 6000을 소폭 넘을 수 있으므로 보고서 수치를 따른다.

확인된 수정 대상: 민트 상의 소매 바깥 원통형 잔여물, 코랄 상의의 팔 기울기 및 밑단 변형, 바지의 잔여 주름과 큰 자세의 허리 변형, 암벽화의 끈·고무와 발목 구멍 형태. 올리브 원본은 긴바지에 가까워 착용 검토본에서 7부 길이로 조정했다. 크기 정렬은 비균일 스케일을 사용한 1차 근사이며 체형에 맞춘 재단·관통 검사를 대체하지 않는다. 상의 검수 이미지 일부는 긴 팔 끝이 프레임 밖에 있어 완전한 실루엣 판정 자료가 아니다.

기존 캐릭터에는 의상 아래 완전한 신체가 없으므로 짧은 바지나 상의를 교체할 때 노출될 신체 표면도 추가 제작해야 한다. 현재 검토본을 곧바로 상용 의상 교체 시스템의 완성 자산으로 사용하지 않는다.

실제 비용: 각 text_to_model 40크레딧 × 6 = 240크레딧, 잔액 390. 작업별 ID와 과금은 costs.json. 최초 하의 입력 두 건은 제출 심사 거절로 비용 0이며 일반 의류 제품 설명으로 수정한 두 작업이 성공했다. jobs.yaml은 최초 실행 계획이므로 실패 이력을 포함하며 결과 비용을 대체하지 않는다.
