# 클라이밍 캐릭터 최종 제작안

2026-11-13 · 남녀 공통 제작 목표 · 3D 모델 및 플레이 검증 전

## 외형과 기준 이미지

키 170cm에 양팔을 펼친 길이 195cm인 카툰풍 클라이머를 만든다. 팔을 대각선으로 길게 뻗었을 때 손과 다음 홀드 사이의 거리가 작은 모바일 화면에서도 읽혀야 한다. 남성 45228.png, 여성 45227.png의 얼굴·헤어·의상을 따른다. 마지막 벽 등반 시안은 후면 실루엣과 동작의 기준이다. 회색 초크백의 부착 위치는 착용자의 오른쪽 뒤 허리다. 후면 카메라에서 화면 오른쪽에 보인다.

## 얼굴 제작 기준

사용자가 다시 첨부한 남성 45228.png와 여성 45227.png를 각각 얼굴의 최우선 기준으로 삼는다. 참고 이미지의 귀엽고 부드러운 애니메이션풍 인상을 정면·사선·측면의 3D 형태와 재질에 반영한다.

| 부위 | 제작 목표 |
| --- | --- |
| 눈 | 크고 둥근 눈매, 짙은 갈색 홍채와 작은 하이라이트. 위쪽 눈꺼풀은 선명하고 아래쪽은 가볍게 표현한다. |
| 볼·턱 | 볼에 부드러운 볼륨을 주고 턱까지 매끄럽게 좁아지는 윤곽을 만든다. 턱끝은 작고 둥글게 마무리한다. |
| 코 | 작은 코와 낮고 부드러운 콧대를 만들고 옅은 명암으로 형태를 읽히게 한다. |
| 입·표정 | 작은 입과 살짝 올라간 입꼬리로 편안하고 옅은 미소를 만든다. |
| 눈썹 | 단순하고 부드러운 곡선으로 눈 위에 배치한다. |
| 피부·명암 | 매끈한 무광 피부와 넓고 부드러운 명암으로 표현한다. 볼과 코의 색 변화는 옅게 둔다. |
| 헤어와 얼굴 | 둥근 머리 덩어리와 부드러운 앞머리가 얼굴을 감싸게 한다. 교체한 헤어에서도 눈과 이마의 표정이 읽혀야 한다. |

남성은 참고의 둥근 눈과 부드러운 볼·턱선을, 여성은 참고의 큰 눈과 작은 코·입, 부드러운 얼굴 윤곽을 각각 따른다. 남녀 얼굴 차이는 각 참고에서 가져온다. 머리 길이는 공통 치수표를 적용하며 얼굴 내부 비율은 참고의 귀여운 인상에 맞춘다.

참고 얼굴과 3D 얼굴의 정면·사선을 같은 크기로 나란히 비교해 채택한다. 마지막 벽 등반 시안은 자세와 후면 실루엣 검토에 사용하며, 얼굴은 이번 첨부 두 장을 기준으로 제작한다. 생성 원형이 기준에 미달하면 눈·코·볼·턱의 형태와 재질을 조정해 확인한다.

## 공통 치수

정면 T포즈, 맨발, 머리카락 제외. 단위는 cm. 이전 175cm 초안을 아래 수치로 대체한다.

| 항목 | 목표 | 측정 기준 |
| --- | ---: | --- |
| 키 / 머리 길이 | 170 / 25 | 6.8등신 |
| 어깨 관절 간격 / 바닥 기준 높이 | 35 / 138 | 관절 중심 |
| 위팔 / 아래팔 / 손 | 35 / 29 / 16 | 어깨 → 팔꿈치 → 손목 → 중지 끝 |
| 한쪽 팔 / 양팔 전체 | 80 / 195 | 어깨부터 손끝까지 80, 양쪽 중지 끝 사이 195 |
| 고관절 / 가랑이 높이 | 89 / 80 | 허벅지 회전 중심과 바지 밑위 |
| 무릎 / 발목 높이 | 48 / 8 | 바닥에서 관절 중심까지 |
| 발 길이 | 25 | 뒤꿈치부터 발가락 끝까지 |

정면 기준 이미지의 팔 길이는 3D 기준 골격에 맞춰 조정한다. 골반 깊이·고관절 간격은 단순한 기준 바디에서 좌우 하이스텝과 옆 뻗기를 보고 결정한다. 허벅지와 종아리의 수직 높이 차는 41·40cm이며, 게임에 입력할 뼈 길이는 확정한 3D 관절 중심 사이에서 잰다.

## 선택 메뉴와 장비

| 선택 | 첫 제작 범위 | 결합 기준 |
| --- | --- | --- |
| 성별 | 남성·여성 바디와 얼굴 | 골격·키·관절·손발 접점 공유 |
| 헤어 | 짧은 갈색 머리·갈색 올림머리 | 두 바디에서 머리뼈 기준으로 교체 |
| 상의 | 흰 반팔·흰 민소매 | 같은 아이템을 체형에 맞춰 착용. 민소매로 드러나는 어깨·겨드랑이 피부까지 제작 |
| 하의 | 남색 긴 바지·짙은 레깅스 | 골반부터 양 발목까지 이어지는 한 벌. 깊은 중앙 홈과 고정된 검은 그림자 방지 |
| 신발 | 노랑·차콜 기본 암벽화 한 켤레부터 제작 | 좌우 한 쌍 단위로 교체. 모든 신발의 앞코가 공통 홀드 접점에 닿도록 제작 |

보라색 하네스와 회색 초크백은 기본 고정 장비로 제안한다. 허리띠는 골반, 다리 고리는 각각의 허벅지를 따르며 연결끈은 굽힘에 따라 변형한다. 하의 교체 시 장비는 새 바지의 두께에 맞춘다.

## 제작 순서

1. 공통 골격으로 정면 T포즈와 팔을 내린 자세를 본다. 정수리와 양발 바닥선을 맞추고 어깨·팔꿈치·손목을 표시해 남녀의 실제 치수를 비교한다.
2. 별도 생성 지시 후 Tripo v3.1로 원형을 만든다. 남녀 정면 그림을 인물별로 입력하며, smart_low_poly와 캐릭터당 최대 15,000삼각형을 시작 설정으로 사용한다. 먼저 한 체의 등반 자세를 검토한 뒤 두 번째 체형으로 확장하는 순서를 제안한다.
3. 편집 도구에서 몸·머리카락·상의·하의·암벽화·장비를 분리하고, 옷을 벗겼을 때 노출될 피부를 복원한다. 공통 골격에 연결하고 하네스와 사타구니의 굽힘을 조정한다. 기존 생성 설정에서는 교체 가능한 메시와 체형별 의상 핏을 후처리로 완성한다.
4. Godot에서 기존 설계의 위팔·아래팔 40·38cm와 새 모델의 35·29cm 차이를 반영한다. 손목부터 그립까지의 거리와 신발 앞코 위치를 별도로 측정한다. 지지 중인 손발은 홀드에 고정하고, 몸통 이동과 어깨 회전으로 다음 홀드에 접근하도록 한다.
5. 두 성별로 R01 시작 네 점과 필수 이동을 재생한다. 기존 루트에서 닿지 않는 구간은 게임 설계 의도와 대조한 뒤 홀드 위치 또는 허용 자세를 조정한다.

## 게임 화면에서의 채택 기준

| 자세 | 화면에서 확인할 것 |
| --- | --- |
| 팔을 내림 → 대각선으로 멀리 뻗음 | 두 자세 모두 길고 가는 팔로 읽히며, 어깨와 소매가 자연스럽게 들리고 팔꿈치 굽힘 방향이 이어진다. |
| 좌우 하이스텝 및 옆으로 다리 뻗기 | 후면·사선에서 둔부 밑선이 허벅지까지 둥글게 이어지고 하네스 고리가 바지를 뚫지 않는다. |
| 한 발 해제 → 반대 손으로 먼 홀드 잡기 | 남은 손·발 접점이 제자리에 있고 손이 닿는 순간과 잡기 판정이 일치한다. |
| 작은 발홀드에서 골반 돌리기 | 앞코가 홀드 위에 머무르고 뒤꿈치가 따라 돈다. 골반 회전은 지지점과 관절 범위 안에서 끝난다. |
| 같은 루트에서 성별·옷·신발 교체 | 홀드 도달 여부가 같고 노출 피부·옷·장비 사이에 틈이나 관통이 나타나지 않는다. |

좌우 동작의 진입·유지·복귀를 실제 후면 플레이 카메라로 기록해 채택한다. 최종 적용물은 공통 골격에 연결된 남녀 바디와 교체 파츠, 손발 접점이 설정된 Godot 캐릭터 장면이다.
